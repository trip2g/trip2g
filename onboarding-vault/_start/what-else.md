A map of the rest, one line each. Follow a link only when you need that thing.

### Getting content in and out

- [Two-way sync](https://trip2g.com/en/user/two-way-sync) — pull server-side edits back into the vault
- [Git access](https://trip2g.com/en/user/git) — your whole site is a git repo at `{{publicUrl}}/_system/git`; clone, commit, push
- [In-browser editor](https://trip2g.com/en/user/editor) — fix a typo from the site itself, no Obsidian needed
- [CLI sync](https://trip2g.com/en/user/cli) — GitHub Actions and other CI pipelines
- [Import from Telegram](https://trip2g.com/en/user/telegram-import) — pull an existing channel's history into the vault

### How the site looks

- [Default template](https://trip2g.com/en/user/default-template) — what you get out of the box, including `wide: true` for full-width pages
- [Theming](https://trip2g.com/en/user/themes) — re-skin the whole site with CSS variables pasted into the admin panel
- [Theme editor](https://trip2g.com/en/user/theme-editor) — do that live, with sliders
- [Custom templates](https://trip2g.com/en/user/templates) — Jet layouts, like `simple_layout.md` in this vault
- [Embedded notes](https://trip2g.com/en/user/embedded-notes) — `![[note]]` as a reusable, styleable block

### Who can read what

- [Subgraphs](https://trip2g.com/en/user/subgraphs) — sections with their own access rules and sidebar
- [Monetization](https://trip2g.com/en/user/monetization) — paid subscriptions to part of your site
- [Telegram group access](https://trip2g.com/en/user/telegram-access) — group membership grants access, both directions
- [Frontmatter patches](https://trip2g.com/en/user/frontmatter-patches) — set properties across whole folders without touching each note

### Being found

- [SEO](https://trip2g.com/en/user/seo) and [robots.txt / llms.txt](https://trip2g.com/en/user/robots_and_llm) — see `robots.md` in this vault
- [RSS](https://trip2g.com/en/user/rss) — see `feed.md`
- [Multilingual sites](https://trip2g.com/en/user/multilingual) and [multi-domain](https://trip2g.com/en/user/multidomains)
- [Search](https://trip2g.com/en/user/search) — how ranking works

### Automation

- [Webhooks](https://trip2g.com/en/user/webhooks) — fire on note changes or on a schedule
- [Forms](https://trip2g.com/en/user/forms) — collect responses from a note
- [Fleet](https://trip2g.com/en/user/fleet) — LLM agents defined as notes in your vault
- [Releases](https://trip2g.com/en/user/releases) — turn off live drafts and ship changes in batches

### Running it

- [Hosting](https://trip2g.com/en/user/hosting) · [Self-hosted](https://trip2g.com/en/user/selfhosted) · [Backups](https://trip2g.com/en/user/backups)
- [OAuth sign-in](https://trip2g.com/en/user/oauth) and [corporate SSO](https://trip2g.com/en/user/oidc)
