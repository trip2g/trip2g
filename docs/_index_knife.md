## A markdown Swiss army knife

trip2g is as flexible as the agents that run it, and it takes just as much understanding. There are thousands of ways to use it, and we can't tell you up front which one is yours. Start with one job: a site from Obsidian, memory for one agent, or a dashboard.

You could build something like it yourself. But trip2g has [more than a year of development](/en/thoughts/anatomy_15_months) behind it, and bugs that have already been found and fixed.
