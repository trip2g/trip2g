# Video scripts

Five short-form scripts (60-90 seconds each). Each sells one idea to the beachhead segment: small trusted peer circles using Obsidian who want a shared community brain without a SaaS middleman.

Voice rules: human, specific, concrete. No hype. See [`../00_brief.md`](../00_brief.md) for the full ban-list.

---

| # | File | Logline | Funnel stage |
|---|------|---------|--------------|
| 1 | [`01-federated-query-trace.md`](01-federated-query-trace.md) | One agent question fans out across two vaults and comes back with one cited answer, without either person exporting a file. | Awareness / aha moment |
| 2 | [`02-git-conflict-horror.md`](02-git-conflict-horror.md) | A `workspace.json` merge conflict in Git versus the same edit syncing clean in trip2g: the structural mismatch, shown. | Problem-aware / consideration |
| 3 | [`03-watch-agents-work.md`](03-watch-agents-work.md) | Watching your agent read and edit across multiple bases live isn't a demo trick. It's the control plane that lets you stop a mistake before it lands. | Consideration / activation |
| 4 | [`04-share-a-slice.md`](04-share-a-slice.md) | Grant a partner's agent access to one folder, watch it succeed, revoke it, watch it fail. The rest of the vault never moved. | Consideration / feature proof |
| 5 | [`05-notes-to-api-60s.md`](05-notes-to-api-60s.md) | `mcp:add ~/notes/research`: 847 files indexed, agent answering grounded questions, nothing left the machine. | Activation / bottom-of-funnel |
