## One week, one trip2g

We didn't add a single component. One instance, the same notes:

1. **[Memory for a support agent](/en/user/agent_memory).** Every night the agent reads the day's conversations with customers and writes down what it learned: pain points, requests, how support resolved them. Plain markdown, and every claim comes with a quote.
2. **[A dashboard for the manager](/en/user/templates).** A template over the frontmatter of those notes: who needs attention, response times, the top topics of the week and the month.
3. **[A second agent, read-only](/en/user/mcp).** One key opens the support base to an analyst agent. It answers the manager and the developers and can't change anything. One command revokes the access.
4. **[The documentation site](/en/user)**, the one you're reading, with search and templates.
5. **[A kanban app](/en/user/kanban)** on top of the [GraphQL API](/en/user/spa) that saves the board back into a note.

Five jobs. One process. One format that people and agents both understand.

This home page is built on trip2g too, with its own layouts. The documentation runs on the [default template](/en/user/default_template): its header, sidebars and table of contents are set by notes, not code.
