trip2g Cloud is a free public playground — one click to a live site, no server setup required.

**[Open the cloud → simplecloud.2pub.me](https://simplecloud.2pub.me)**

Go to [simplecloud.2pub.me](https://simplecloud.2pub.me), sign in, click **Open as Admin**. You land as the admin of a real running site on a randomly assigned subdomain like `honesthesse.2pub.me`. From there the flow is the same as any trip2g instance: download the starter vault, open it in Obsidian, sync, and your site updates.

### How to start

1. Open [simplecloud.2pub.me](https://simplecloud.2pub.me)
2. Sign in with your email and password (or GitHub / Google)
3. Click **Open as Admin** on your assigned space
4. Download the starter vault from the welcome page, open it in Obsidian
5. Press Sync — your notes go live at your subdomain

See [[en/user/getting-started|Getting started]] for a full walkthrough of the Obsidian sync flow.

### What this is — and what it isn't

This is a sandbox. Best-effort, no SLA, no backups. Each space has a ~100 MB quota. Don't store anything you can't afford to lose.

It's the right place to try trip2g, build a demo, or show someone how the platform works. It's not a permanent home for a real site.
