A fake JSON API used by the [[chartdata|charts documentation]] demo. It returns a
small daily-revenue series as JSON, served by the `fakeapi/products` layout. Open
the page URL and you get raw JSON instead of a normal page — that is the whole
point: a `url` datachart source can fetch it, and so can anyone who copies the
example into their own vault.
