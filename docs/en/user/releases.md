Releases let you publish content in batches rather than note by note.

### How it works

Write notes in Obsidian and sync them to the server. Readers can't see them — the content sits in drafts.

When you're ready to publish, create a release in the admin panel. All changes go live at once.

### Why releases

**Personal blogs** — write notes in any order, edit and refine them. Readers see only the final version after a release.

**Editorial workflow** — an author writes, an editor reviews drafts in the admin panel. After revisions, create a release — everything publishes together.

**Related posts** — write a series of five articles and publish them in one release so readers see the full series at once, not one article per week.

### Creating a release

1. Open the admin panel
2. Go to **Releases**
3. Click **+ Add**
4. Click **Submit**

All drafts become public immediately.

### Draft mode for testing

Creating a release for every note while getting started is inconvenient. Enable draft mode instead:

- Open Settings → **+ Change**
- Enable **Show Draft Versions**
- Click Submit

Your notes become visible immediately after sync — no release needed.

This only applies to administrators. Regular readers never see drafts.
