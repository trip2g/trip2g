What's done, what's partial, and what's next.

### Works now

- **Mermaid diagrams** — any ` ```mermaid ` block renders as a diagram.
- **Charts** — ` ```datachart ` blocks render as interactive Apache ECharts.
- **Forms in notes** — collect signups or contact requests directly from a note.
- **Webhooks and cron** — trigger external services on note changes or on a schedule.
- **MCP Federation** — one search endpoint across multiple knowledge bases.
- **In-browser editor** — edit and roll back notes without reopening Obsidian.
- **Telegram publishing** — schedule posts, publish albums, edit after publishing.
- **Canvas-driven Telegram navigation** — a `.canvas` file can power a navigation bot in Telegram.
- **Monetization** — Patreon, Boosty, crypto payments, Telegram group gating.

### Partial — synced, but a placeholder on the web

- **Canvas** (`.canvas`) — files sync and power Telegram navigation, but the published web page shows a placeholder, not the board. See [[canvas]].
- **Excalidraw** (`.excalidraw`) — files sync without errors; web rendering is planned.
- **Obsidian Base** (`.base`) — same: sync works, web rendering is planned.
- **`datachart` internal source** — charts from your site's own SQL data are designed but not yet enabled.

### Planned

- Web rendering for Canvas, Excalidraw, and Base on published pages.
- `datachart` internal source: query your own notes as chart data.

If you need something that's missing or want to influence priority, leave a note on [[version_requests]].
