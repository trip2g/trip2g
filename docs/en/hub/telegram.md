# Telegram Channels

Search across a curated set of public Telegram channels, indexed by a trip2g
Telegram adapter and federated into this hub — semantic search over their message
history.

Note: the adapter authenticates with a federation key configured in admin. Until
that key is set, anonymous queries return no results.
