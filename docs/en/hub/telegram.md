# Telegram Channels

Semantic search over a curated set of **public** Telegram channels.

Unlike the other entries, this base is **not a trip2g instance**. It's a standalone
node — Qdrant plus a Telegram indexer — that simply implements the MCP federation
protocol. It has no public access of its own: the only way in is through this hub,
which holds its key (configured in the trip2g admin). A small proof that the hub
federates *any* node speaking the protocol, not just trip2g bases.
