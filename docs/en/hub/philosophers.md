# Philosophers Hub

A routing hub over 21 philosopher knowledge corpora — author cards, a topic
position matrix, and a contradictions index. The full corpora (concepts,
principles with verbatim anchored quotes, argument chains) are reached through
this one peer: `federated_search(kb_id="philosophers")` searches the hub itself
(cards, topic matrix); a specific corpus is addressed through it with a nested
id, e.g. `federated_search(kb_id="philosophers/nietzsche")`.

**Base:** https://philosophers.2pub.me · `kb_id: philosophers`
