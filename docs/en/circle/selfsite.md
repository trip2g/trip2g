trip2g.com runs on trip2g: the documentation, the essays in Philosophy, the changelog, the landing and this wheel are notes in one vault, synced to the server like any other. The docs are structured pages with headings; the essays are a garden, undated, linked to each other and edited in public; the changelog is the stream, dated releases newest on top. Docs and garden share one graph: the MCP page links to the essay with the measurements behind its search fields, and the essay links back.
