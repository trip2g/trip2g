Claude Code, Codex or any MCP agent starts every session blank. Point it at trip2g and what it learns stays as markdown notes: the next session finds them by search and reads only the section it needs. The memory is files you can read, diff and fix by hand, the same on every machine and shared with a team. memcli boots a local server in one command.
