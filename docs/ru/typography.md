## Абзацы

Абзац — это блок текста, отделённый пустыми строками. Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.

Второй абзац идёт после пустой строки. Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat.

---

## Выделение

**Жирный текст** оборачивается двойными звёздочками.

*Курсивный текст* оборачивается одинарными звёздочками.

***Жирный курсив*** использует тройные звёздочки.

~~Зачёркнутый текст~~ оборачивается двойными тильдами.

## Списки

### Маркированный

- Первый пункт
- Второй пункт
  - Вложенный пункт
  - Ещё вложенный
    - Глубоко вложенный
- Третий пункт

### Нумерованный

1. Первый пункт
2. Второй пункт
3. Третий пункт
   1. Подпункт
   2. Подпункт

### Список задач

- [x] Выполненная задача
- [x] Тоже выполнена
- [ ] Ещё не выполнена
- [ ] Другая задача

## Код

### Инлайн-код

Используйте `инлайн-код` для коротких фрагментов, имён переменных вроде `myVar` или команд типа `git status`.

### Блоки кода

```python
def greet(name: str) -> str:
    return f"Привет, {name}!"

print(greet("мир"))
```

```javascript
const add = (a, b) => a + b;

console.log(add(2, 3)); // 5
```

```go
package main

import "fmt"

func main() {
    fmt.Println("Привет, мир!")
}
```

```bash
# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

```json
{
  "name": "мой-сайт",
  "version": "1.0.0",
  "description": "Опубликовано через trip2g"
}
```

```
Блок без подсветки синтаксиса.
Подходит для конфигурационных файлов, логов и т.д.
```

## Таблицы

| Поле        | Тип      | Обязательно | Описание                      |
|-------------|----------|-------------|-------------------------------|
| `title`     | строка   | Нет         | Заголовок страницы            |
| `free`      | булево   | Нет         | Видна без авторизации         |
| `date`      | дата     | Нет         | Дата публикации               |
| `tags`      | список   | Нет         | Теги для фильтрации           |

Выравнивание:

| По левому краю | По центру | По правому краю |
|:---------------|:---------:|----------------:|
| Ячейка         |  Ячейка   |         Ячейка  |
| Длинное значение |   Центр   |           12345 |
