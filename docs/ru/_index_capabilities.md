- **[Публикация из Obsidian](/ru/user/dvukhstoronnyaya_sinkhronizaciya)** — хранилище остаётся у вас; синхронизация отправляет заметки на сайт, в одну или в обе стороны.
- **[Публикация в Telegram](/ru/user/telegram)** — пишете один раз в Obsidian, постите в канал по расписанию, ссылки не ломаются.
- **[Платный доступ](/ru/user/monetization)** — уберите `free: true` — и заметка только для подписчиков; оплата через крипту, Patreon или Boosty.
- **[ИИ, который отвечает по вашим заметкам](/ru/user/mcp)** — подключите любой MCP-клиент, и читатель спрашивает вашу базу знаний напрямую.
- **[Внешний вид под вас](/ru/user/templates)** — собирайте страницы из виджетов во фронтматтере или подключите свои Jet-шаблоны.
- **[Свой сервер](/ru/user/selfhosted)** — один Go-процесс на SQLite; `docker compose up` на ноутбуке, VPS или Fly.
