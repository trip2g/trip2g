# Память для агента, которую вы читаете в *Obsidian*.

Агент пишет заметки. Вы читаете и редактируете их в Obsidian. Читатели видят те же заметки как сайт. Агент задаёт вопрос одному хабу, а хаб ищет ответ по всем подключённым базам: вашим и тех, кому вы доверяете.

одна заметка: страница для человека, вызов инструмента для агента
