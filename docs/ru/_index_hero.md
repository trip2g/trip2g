# Сайт из вашего *Obsidian*. И память для ваших агентов.

Пишете заметки в Obsidian, нажимаете Sync — заметки становятся сайтом. Добавляете адрес хаба в Claude Code или Cursor — агент отвечает по вашим заметкам и указывает источники.
