# Бенджамин Франклин — Автобиография и Путь к богатству

База знаний посвящена Бенджамину Франклину через две ключевые работы: «Автобиографию»
и «Путь к богатству» (дайджест максим Бедного Ричарда). Каждое утверждение подкреплено
дословной цитатой из этих источников.

Охватывает: систему 13 добродетелей как практических навыков, метод самоулучшения
через эксперимент (таблица добродетелей, ежедневная проверка, расписание дня),
гражданские проекты (Junto, первую библиотеку), философию Бедного Ричарда о времени,
деньгах и труде, понимание честности и скромности как рабочих стратегий.
