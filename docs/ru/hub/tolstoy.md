# Лев Толстой — Исповедь

База знаний мировоззрения Льва Толстого, извлечённого из философского трактата
«Исповедь» (1879–1882, РУ ПСС т. 23). Охватывает кризис веры, проверку разума,
духовное обращение и разрыв с церковью.

Структурирована в 36 концептов, 16 принципов в 5 доменах и 4 смысловых цепочки.
Каждое утверждение подкреплено дословной цитатой корпуса с указанием главы.
