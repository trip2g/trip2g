# Джеймс Аллен — As a Man Thinketh

База знаний по первичному тексту Джеймса Аллена (1864–1912) **«As a Man Thinketh»**
(1903, Authorized Edition; Gutenberg #4507) — краеугольное эссе о власти мысли, где
один закон развёрнут по семи главам: мысль → характер → обстоятельство → тело →
судьба.

7 концептов, охватывающих связь мышления с условиями жизни и судьбой, 7 принципов
для запоминания и дебатов, 3 цепочки внутриглавных аргументов. Каждое утверждение
подкреплено дословной цитатой.
