# Хаб философов

Маршрутизирующий хаб над 21 корпусом философов — карточки авторов, матрица
позиций по темам и индекс противоречий. Полные корпуса (концепты, принципы с
дословными привязанными цитатами, цепочки аргументов) доступны через один пир:
`federated_search(kb_id="philosophers")`, а конкретный корпус — по его `kb_id`
(например, `nietzsche`, `tolstoy`).
