# Эпиктет — Энхиридион

База знаний по учению Эпиктета (ок. 55–135 н.э.) — древнегреческого философа-стоика.
Корпус: «Энхиридион» (Мануал), сжатый свод философии в 52 главах, составленный его
учеником Аррианом.

Исследует ядро стоической этики Эпиктета: дихотомию контроля (подвластное и
неподвластное), роль суждения в страдании, свободу через отказ от внешнего и путь
ученика к невозмутимости. Каждое утверждение подкреплено дословными цитатами из
перевода Джорджа Лонга.
