# Сэмюэл Смайлс — Self-Help

База знаний по книге «Self-Help» (1859) Сэмюэла Смайлса — викторианской книге о
самосовершенствовании, родоначальнице всего жанра self-help. Извлечена из
английского оригинала (Gutenberg #935); каждое утверждение подкреплено дословной
цитатой из текста.

Смайлс проповедует рост изнутри вместо упования на помощь извне; упорство и
приложение сил против культа гения; трудолюбие как образование, не как источник
богатства; характер как истинный венец жизни.
