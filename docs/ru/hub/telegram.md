# Telegram-каналы

Семантический поиск по курируемому набору **публичных** Telegram-каналов.

В отличие от других записей, это **не trip2g-инстанс**. Это отдельная нода — Qdrant
плюс индексатор Telegram, — которая просто реализует протокол MCP-федерации. Сама по
себе она недоступна: попасть внутрь можно только через этот хаб, у которого есть
ключ (прописан в админке trip2g). Небольшое доказательство, что хаб подключает
*любую* ноду, говорящую на этом протоколе, а не только trip2g-базы.
