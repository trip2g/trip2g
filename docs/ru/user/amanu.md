[Amanu](https://amanu.me/ru/) записывает и расшифровывает созвоны на вашем компьютере. Небольшой скрипт после каждой встречи отправляет расшифровку в вашу базу trip2g. Нажимать ничего не нужно.

Пошаговая установка с готовыми файлами: [trip2g.github.io/amanu](https://trip2g.github.io/amanu/). Исходники: [github.com/trip2g/amanu](https://github.com/trip2g/amanu).

### Что получается

После каждого звонка в базе появляется заметка в папке `calls`, названная по дате и времени встречи. В ней расшифровка и, если Amanu её сделал, выжимка. Заметка сразу попадает в поиск, в том числе через [[mcp|MCP-сервер]].

Звук не отправляется. В базу уходит только текст.

### Что понадобится

| Что | Где взять |
|---|---|
| Windows 11 версии 24H2 или новее | этого требует сам Amanu |
| Адрес базы | `https://ваш-сайт/_system/graphql` |
| API-ключ | **Администрирование → API-ключи** |

API-ключ даёт права администратора на весь контент. Храните файл настроек как пароль и отзывайте потерянный ключ в том же разделе.

### Установка

1. Поставьте Amanu с [amanu.me](https://amanu.me/ru/). В окне первой настройки выберите локальную расшифровку. Для русской речи подходит модель GigaAM v3.
2. Выключите «Саммари», если не подключаете для него модель. Пока Amanu ждёт саммари, которое некому сделать, скрипт после встречи не запускается.
3. Положите в одну папку `amanu-to-trip2g.ps1` и файл настроек `amanu-to-trip2g.json`:

   ```json
   {
     "endpoint": "https://ваш-сайт/_system/graphql",
     "apiKey": "ваш ключ",
     "folder": "calls"
   }
   ```

4. В Amanu откройте «Настройки…» → «Дополнительно» → «Запускать после каждой встречи». Программа: `powershell.exe`. Аргументы, каждый на своей строке:

   ```
   -NoProfile
   -ExecutionPolicy
   Bypass
   -WindowStyle
   Hidden
   -File
   C:\Users\ВАШЕ_ИМЯ\amanu-trip2g\amanu-to-trip2g.ps1
   {session}
   ```

5. Закройте окно настроек. Amanu сохраняет это поле только при закрытии окна.

### Как проверить

Проведите звонок дольше минуты. Когда Amanu закончит расшифровку, заметка появится в папке `calls`.

Рядом со скриптом лежит журнал `amanu-to-trip2g.log`. Строка `OK` значит, что заметка ушла. Строка `FAIL` объясняет, что помешало.

### Как это устроено

Amanu умеет запускать программу после каждой встречи и передаёт ей папку встречи. Скрипт читает оттуда `transcript.md` и `summary.md`, собирает одну заметку и отправляет её мутацией `pushNotes` с заголовком `X-API-Key`. Это тот же запрос, которым пользуются [[cli|CLI]] и плагин для Obsidian. Подробнее про API: [[graphql]].

### Ограничения

- Только Windows. Скрипта для macOS пока нет.
- Повторной отправки нет. Если в момент окончания встречи не было интернета, заметка не уйдёт, а в журнале останется строка `FAIL`.
- При локальной расшифровке говорящие размечены только как «я» и «они».
