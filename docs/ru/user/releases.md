title: Релизы
---

Релизы позволяют публиковать контент партиями, а не по одной заметке.

### Как это работает

Вы пишете несколько заметок в Obsidian и синхронизируете их с сервером. Читатели их не видят — контент находится в черновиках.

Когда готовы опубликовать — создаёте релиз в админ-панели. Все изменения выходят одновременно.

### Зачем нужны релизы

**Для личных блогов:**
Вы можете писать заметки в любом порядке, править их, дополнять. Читатели увидят только финальную версию после релиза.

**Для блогов с редакцией:**
Автор пишет, редактор проверяет черновики в админ-панели. После правок создаёте релиз — всё публикуется разом.

**Для связанных постов:**
Пишете серию из 5 статей. Публикуете их одним релизом — читатели сразу видят всю серию, а не по одной статье в неделю.

### Как создать релиз

1. Откройте админ-панель
2. Перейдите в раздел «Releases»
3. Нажмите «+ Add»
4. Нажмите «Submit»

Готово. Все черновики стали публичными.

### Режим черновиков для тестирования

Во время знакомства с сервисом создавать релиз для каждой заметки неудобно.

Включите режим черновиков в настройках:
- Откройте «Настройки» → «+ Change»
- Включите флаг «Show Draft Versions»
- Нажмите «Submit»

Теперь ваши заметки видны сразу после синхронизации. Релизы не нужны.

Важный момент: режим черновиков работает на весь сайт. Когда он включён, все посетители сразу видят свежие заметки — релизы по сути отключаются. В этом и смысл: публиковать правки, не создавая релиз каждый раз. Нужно собирать правки партиями и прятать незаконченное — выключите режим и пользуйтесь релизами.
