---
Свойства — структурированные данные в начале заметки. Они управляют публикацией: заголовок, URL, доступ, время публикации в Telegram.

### Как добавить свойство

Несколько способов:
- Команда «Add file property» (Cmd/Ctrl + ;)
- Правый клик на вкладке → «Add file property»
- Напишите `---` в самом начале файла

Свойства хранятся в формате YAML:

```yaml
---
title: Моя заметка
free: true
---
```

### Типы свойств

Obsidian поддерживает разные типы данных:

| Тип | Пример | Описание |
|-----|--------|----------|
| Text | `title: Заголовок` | Текстовая строка |
| Checkbox | `free: true` | Да/нет |
| List | `tags: [a, b]` | Список значений |
| Date & time | `2025-01-15T09:00` | Дата и время |

Важно выбрать правильный тип. Например, `telegram_publish_at` должен быть «Date & time», а не просто «Date».

### Основные свойства

**free** (Checkbox)
Открывает заметку для всех. Без этого свойства страница видна только авторизованным пользователям.

```yaml
free: true
```

**title** (Text)
Заголовок страницы. Если не указан — берётся из имени файла.

```yaml
title: Как начать работу
```

**description** (Text)
Описание для поисковиков и превью в соцсетях.

```yaml
description: Пошаговая инструкция по настройке сервиса
```

**slug** (Text)
Кастомный URL страницы. Заменяет автоматический URL из имени файла.

```yaml
slug: getting-started
```

Результат: `yoursite.com/getting-started` вместо `yoursite.com/Как_начать_работу`

**subgraphs** (Text или List)
Привязывает заметку к курсу или разделу с отдельным сайдбаром.

```yaml
subgraphs: premium
```

### Свойства для Telegram

**telegram_publish_at** (Date & time)
Дата и время публикации поста в Telegram. Важно: выбирайте тип «Date & time», не просто «Date».

```yaml
telegram_publish_at: 2025-01-15T09:00
```

**telegram_publish_tags** (List)
Теги для привязки к каналам. Заметка публикуется во все каналы с совпадающими тегами.

```yaml
telegram_publish_tags:
  - Новости
  - Анонсы
```

Официальная документация: [Properties](https://help.obsidian.md/properties)

- Cmd/Ctrl + ; — добавить свойство
- Tab / Shift+Tab — переход между свойствами
- Cmd/Ctrl + Backspace — удалить свойство
