Все люди разные. Один материал можно воспринимать по-разному в зависимости от порядка прочтения.

### Проблема обычных книг

Оглавление в книге — как папки для навигации. Удобно, но ограничивает одним порядком чтения. Автор решает за читателя, как двигаться по материалу.

### Как это работает

**Свободная навигация:**
- Читатель перемещается по связям между заметками
- Каждый строит свой путь через материал
- Нет единственно правильного порядка

**AI как проводник:**
- AI генерирует персональное оглавление
- Учитывает интересы и уровень читателя
- Читатель задаёт вопросы напрямую тексту

### Результат

Книга адаптируется под каждого. Вместо одного маршрута — множество путей через знания.
