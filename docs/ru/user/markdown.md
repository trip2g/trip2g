Markdown — язык разметки для форматирования текста. Файлы имеют расширение `.md`. Все заметки в trip2g — это Markdown-файлы.

### Заголовки

```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3
```

Чем больше решёток, тем меньше заголовок.

### Форматирование текста

```markdown
**жирный текст**
*курсив*
~~зачёркнутый~~
`код в строке`
```

Результат: **жирный текст**, *курсив*, ~~зачёркнутый~~, `код в строке`

### Списки

Ненумерованный:
```markdown
- первый пункт
- второй пункт
- третий пункт
```

Нумерованный:
```markdown
1. первый пункт
2. второй пункт
3. третий пункт
```

### Ссылки

Обычная ссылка:
```markdown
[текст ссылки](https://example.com)
```

Wikilink (ссылка на другую заметку):
```markdown
[[Название заметки]]
```

Wikilinks — главная фишка Obsidian. Подробнее: [Obsidian и связи между заметками](/thoughts/obsidian)

### Изображения

```markdown
![описание картинки](путь/к/картинке.png)
```

Можно вставлять картинки из папки с заметками или по URL.

### Цитаты

```markdown
> Это цитата.
> Может быть многострочной.
```

Результат:
> Это цитата.
> Может быть многострочной.

### Код

Блок кода с подсветкой синтаксиса:

````markdown
```javascript
function hello() {
  console.log("Hello, world!");
}
```
````

Укажите язык после первых трёх обратных кавычек для подсветки.

### Горизонтальная линия

```markdown
---
```

Три дефиса создают разделитель.

### Таблицы

```markdown
| Колонка 1 | Колонка 2 |
|-----------|-----------|
| Ячейка 1  | Ячейка 2  |
| Ячейка 3  | Ячейка 4  |
```

Результат:

| Колонка 1 | Колонка 2 |
|-----------|-----------|
| Ячейка 1  | Ячейка 2  |
| Ячейка 3  | Ячейка 4  |

### Чекбоксы

```markdown
- [ ] незавершённая задача
- [x] завершённая задача
```

### Frontmatter

В начале файла можно добавить метаданные в формате YAML:

```markdown
---
title: "Название заметки"
free: true
---

Текст заметки начинается после второго ---
```

Frontmatter используется для настройки публикации в trip2g. Подробнее: [Свойства заметок](/docs/properties)

### Видео

Встройте видеофайл из хранилища через `![[...]]`:

```markdown
![[demo.mp4]]
```

Поддерживаемые форматы: `.mp4`, `.avi`, `.mov`, `.mkv`, `.webm`, `.m4v`. Файл рендерится как `<video>`-плеер с элементами управления.

### Аудио

Встройте аудиофайл так же:

```markdown
![[запись.mp3]]
```

Поддерживаемые форматы: `.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a`, `.aac`. Файл рендерится как `<audio>`-плеер с элементами управления — читатель может воспроизводить, ставить на паузу и перематывать без перехода на другую страницу.

Синтаксис изображений Markdown тоже запускает аудиоплеер для аудиофайлов:

```markdown
![](запись.mp3)
```

### Документы (ссылки для скачивания)

Если встроить документ через `![[...]]`, trip2g рендерит его как ссылку для скачивания, а не пытается отобразить содержимое:

```markdown
![[отчёт.pdf]]
![[данные.xlsx]]
```

Поддерживаются как ссылки для скачивания: `.pdf`, `.doc`, `.docx`, `.xls`, `.xlsx`, `.ppt`, `.pptx`, `.txt`, `.rtf`, `.odt`, `.ods`, `.odp`, `.csv`, `.zip`, `.rar`, `.7z`.

Ссылка показывает имя файла и скачивает файл при клике.

## Особенности рендеринга

### Что рендерит trip2g

Рендерер построен на [Goldmark](https://github.com/yuin/goldmark) с расширением GitHub Flavored Markdown (GFM). Это означает, что из коробки работают:

- Стандартный Markdown: заголовки, жирный, курсив, цитаты, блоки кода, горизонтальные линии
- Расширения GFM: таблицы, зачёркивание (`~~`), списки задач (`- [x]`), автоссылки (URL без разметки становятся кликабельными)
- Wikilinks и синтаксис вставки (`![[...]]`)
- Подсветка синтаксиса в блоках кода — серверная, без клиентского JS
- URL YouTube в синтаксисе изображений рендерятся как встроенные плееры: `![](https://youtube.com/watch?v=...)`
- Аудиофайлы встраиваются как `<audio controls>`-плееры
- Видеофайлы встраиваются как `<video controls>`-плееры
- Документы встраиваются как ссылки для скачивания

### Что не рендерится

- **Сноски** — синтаксис `[^1]` / `[^1]: ...` не обрабатывается. Маркеры отображаются как обычный текст.
- **Математика / LaTeX** — блоки `$...$` и `$$...$$` не рендерятся. Содержимое выводится как обычный текст.
- **Типографские кавычки** — прямые кавычки `"..."` не преобразуются в парные `"..."` / `«...»`.
- **Произвольный HTML** — встроенный HTML санируется. Допускается небольшой набор безопасных тегов: `<u>`, `<mark>`, `<sup>`, `<sub>`, `<strong>`, `<em>`.

### Разрешение wikilinks

trip2g разрешает wikilinks так же, как Obsidian: глобально, по имени файла, а не по относительному пути. `[[заметка]]` найдёт любой файл с именем `заметка.md` в любом месте хранилища. При совпадении имён приоритет получает файл с более коротким путём от корня хранилища.

Чтобы указать конкретный файл, используйте явный путь: `[[папка/заметка]]`.

### URL ассетов

Файлы, прикреплённые к заметке (изображения, аудио, видео, документы), хранятся в облаке и отдаются по подписанному URL. URL обновляются автоматически — повторная синхронизация файлов для сохранения доступа не нужна.
