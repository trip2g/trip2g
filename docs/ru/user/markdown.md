Markdown — язык разметки для форматирования текста. Файлы имеют расширение `.md`. Все заметки в trip2g — это Markdown-файлы.

### Заголовки

```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3
```

Чем больше решёток, тем меньше заголовок.

### Форматирование текста

```markdown
**жирный текст**
*курсив*
~~зачёркнутый~~
`код в строке`
```

Результат: **жирный текст**, *курсив*, ~~зачёркнутый~~, `код в строке`

### Списки

Ненумерованный:
```markdown
- первый пункт
- второй пункт
- третий пункт
```

Нумерованный:
```markdown
1. первый пункт
2. второй пункт
3. третий пункт
```

### Ссылки

Обычная ссылка:
```markdown
[текст ссылки](https://example.com)
```

Wikilink (ссылка на другую заметку):
```markdown
[[Название заметки]]
```

Wikilinks — главная фишка Obsidian. Подробнее: [Obsidian и связи между заметками](/thoughts/obsidian)

### Изображения

```markdown
![описание картинки](путь/к/картинке.png)
```

Можно вставлять картинки из папки с заметками или по URL.

### Цитаты

```markdown
> Это цитата.
> Может быть многострочной.
```

Результат:
> Это цитата.
> Может быть многострочной.

### Код

Блок кода с подсветкой синтаксиса:

````markdown
```javascript
function hello() {
  console.log("Hello, world!");
}
```
````

Укажите язык после первых трёх обратных кавычек для подсветки.

### Горизонтальная линия

```markdown
---
```

Три дефиса создают разделитель.

### Таблицы

```markdown
| Колонка 1 | Колонка 2 |
|-----------|-----------|
| Ячейка 1  | Ячейка 2  |
| Ячейка 3  | Ячейка 4  |
```

Результат:

| Колонка 1 | Колонка 2 |
|-----------|-----------|
| Ячейка 1  | Ячейка 2  |
| Ячейка 3  | Ячейка 4  |

### Чекбоксы

```markdown
- [ ] незавершённая задача
- [x] завершённая задача
```

### Frontmatter

В начале файла можно добавить метаданные в формате YAML:

```markdown
---
title: "Название заметки"
free: true
---

Текст заметки начинается после второго ---
```

Frontmatter используется для настройки публикации в trip2g. Подробнее: [Свойства заметок](/docs/properties)
