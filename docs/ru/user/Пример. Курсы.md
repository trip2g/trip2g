База знаний может быть разделена на несколько курсов. Каждый курс продаётся отдельно, но опирается на общее ядро знаний.

### Как это работает

**Структура:**
- Общее ядро — базовые знания, доступные всем покупателям
- Курсы — специализированные части базы
- Лендинги — отдельные страницы для рекламы каждого курса

**Что получает покупатель:**
- Доступ к выбранному курсу
- Доступ к общему ядру знаний
- Связи между темами курса и ядра

### Зачем делить базу на курсы

Вместо одного большого продукта — несколько целевых:
- Разная аудитория покупает разные курсы
- Проще тестировать спрос на отдельные темы
- Можно создавать десятки лендингов для каждого курса и тестировать тексты

### Развитие знаний

Знания постоянно развиваются. Создать новый курс поверх существующего ядра проще, чем начинать с нуля. Ядро растёт — курсы становятся ценнее.
