Короткая ссылка `[[Имя]]` по умолчанию ведёт на **самый неглубокий файл в хранилище** — тот, чей путь от корня короче всего. Это совпадает с поведением Obsidian: одна и та же ссылка всегда ведёт на один и тот же файл, независимо от того, из какой заметки она стоит.

### Поведение по умолчанию: global

trip2g берёт файл с наименьшим количеством сегментов в пути. Если два файла называются одинаково, побеждает тот, что ближе к корню. При равной глубине — тот, чей полный путь идёт первым по алфавиту.

Пример:

```
en/user/templates.md
ru/user/templates.md
```

Короткая ссылка `[[Templates]]` из любой заметки хранилища ведёт на тот из этих двух файлов, который лежит неглубже. Если они на одной глубине, побеждает `en/user/templates.md` — первый по алфавиту. Результат не зависит от того, где стоит ссылка.

Хранилища, собранные в Obsidian, работают без дополнительных настроек.

### Режим по выбору: scoped

Для многоязычных сайтов можно включить разрешение с учётом языка. Задайте в настройках сайта:

```
wikilink_resolution: scoped
```

В режиме scoped trip2g проходит три шага и останавливается на первом совпадении:

1. **Та же папка.** Побеждает заметка из той же папки, где стоит ссылка.
2. **Тот же язык.** Иначе побеждает заметка на том же языке. Язык берётся из свойства `lang` во фронтматтере или из папки верхнего уровня (`en/`, `ru/`).
3. **Кратчайший путь.** Иначе побеждает заметка ближе всего к корню хранилища.

Ничья на любом шаге разрешается по алфавиту.

В режиме scoped короткая `[[Templates]]` из `en/user/getting-started.md` ведёт на `en/user/templates.md`, а та же ссылка из `ru/user/Начало работы.md` — на `ru/user/templates.md`. Короткие ссылки остаются в своём языке без явных путей.

Режим scoped подходит, если:
- В хранилище есть параллельные структуры на двух и более языках.
- Короткие ссылки должны по умолчанию вести к контенту на том же языке.
- Явный путь нужен только тогда, когда вы намеренно ведёте в другой язык.

### Как задать точную цель

Добавьте путь, чтобы указать конкретный файл. Работает одинаково в обоих режимах.

```markdown
[[folder/Name]]
[[en/user/Name]]
[[./Name]]
```

- `[[folder/Name]]` и `[[en/user/Name]]` — путь от корня хранилища.
- `[[./Name]]` — путь относительно заметки со ссылкой.

Пример. Из русской заметки вы хотите отправить читателя к английскому оригиналу:

```markdown
Смотрите [[en/user/templates|английскую версию]].
```
