Иногда страница должна быть полностью на HTML — лендинг, кастомная главная или демо-страница. trip2g поддерживает это без специальных режимов: напишите HTML в теле заметки, назначьте минимальный шаблон — и шаблон выведет содержимое как есть.

### Как это работает

**Шаг 1.** Создайте файл `_layouts/html-page.html`:

```jet
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>{{ note.Title() }}</title>
</head>
<body>
  {{ note.HTMLString() | unsafe }}
</body>
</html>
```

Фильтр `| unsafe` отключает экранирование. Без него угловые скобки превращаются в `&lt;` и `&gt;` — HTML отобразится как текст.

**Шаг 2.** Создайте заметку (например, `my-page.md`) и укажите шаблон:

```yaml
---
title: Мой лендинг
layout: html-page
free: true
---
```

**Шаг 3.** Напишите HTML в теле заметки:

```html
<section class="hero">
  <h1>Привет, мир</h1>
  <p>Полностью кастомная HTML-страница.</p>
  <a href="/signup" class="btn">Начать</a>
</section>
```

После синхронизации `my-page.md` публикуется как страница с вашим HTML в теле.

### Когда это нужно

- Кастомная главная страница сайта (`slug: /`)
- Лендинг продукта
- Демо или портфолио
- Любая страница, где возможностей markdown недостаточно

### Примечания

URL страницы формируется из имени файла. Чтобы сделать страницу корнем сайта, добавьте в frontmatter `slug: /`.

CSS и JS размещайте в `_assets/` и подключайте через `asset()` в шаблоне:

```jet
<link rel="stylesheet" href="{{ asset("landing.css") }}">
```

Подробнее о переменных шаблона, подключении файлов и многофайловых шаблонах — в [[ru/user/templates|Шаблонах]].
