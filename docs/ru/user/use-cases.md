Пять способов использовать trip2g для публикации из Obsidian.

### Цифровой сад

Автор ведёт личную базу знаний в Obsidian — взаимосвязанные заметки, двусторонние ссылки, идеи, которые растут месяцами. Хранилище остаётся на компьютере. trip2g публикует его как сайт. Читатели навигируют по связям, а не по датам. Граф, который автор строит для себя, становится структурой, по которой перемещаются читатели.

→ См. [[ru/user/digital-garden|Цифровой сад]]

### Ютубер

За каждым роликом — сценарий и проработанная статья. Ролик охватывает поверхность, статья держит доказательства, источники и рассуждения. Патроны получают доступ к полной базе знаний: статьи за роликами, связи между темами, AI для вопросов по всей базе. Подписчики Patreon и Boosty получают доступ автоматически.

→ См. [[ru/user/telegram|Публикация в Telegram]]

### AI-консультант

Специалист описывает свою экспертизу в базе знаний. AI-бот отвечает на типовые вопросы клиентов по этой базе — круглосуточно. Специалист просматривает разговоры и заполняет пробелы там, где AI не справился. Несколько специалистов могут объединить знания в одну базу, и AI получит доступ ко всей экспертизе сразу.

→ См. [[ru/user/mcp|AI-ассистент (MCP)]]

### Telegram-канал

Автор пишет посты в Obsidian и публикует их в Telegram-канал по расписанию через `telegram_publish_at`. Каждый пост выходит и на сайте — с деталями, картинками, ссылками. Подписчики платной Telegram-группы автоматически получают доступ к расширенному контенту на сайте — монетизация без сторонних платёжных платформ.

→ См. [[ru/user/telegram|Публикация в Telegram]]

### Документация проекта

Документация живёт в том же репозитории, что и код. CI/CD-пайплайн отправляет файлы в trip2g при каждом изменении — опубликованные доксы всегда соответствуют кодовой базе. Менеджеры и нетехнические коллеги читают документацию на сайте без доступа к репозиторию. Чейнджлоги релизов публикуются автоматически как Telegram-посты.

→ См. [[ru/user/telegram|Публикация в Telegram]], [[ru/user/change_webhooks|Вебхуки при изменении заметок]]
