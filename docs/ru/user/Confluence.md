Корпоративный стандарт для баз знаний. Интеграция с Jira, знакомый интерфейс, но цена растёт с каждым сотрудником.

### Главная проблема: цена за голову

Confluence берёт деньги за каждого пользователя. 10 человек — одна цена. 100 — в десять раз больше. 1000 — уже серьёзный бюджет.

А читать документацию нужно всем. Новичок на онбординге, менеджер ищет регламент, разработчик смотрит API — все платные места.

**trip2g: платите за софт, не за людей**

Фиксированная цена за платформу и хранилище. Сколько угодно писателей, сколько угодно читателей. Добавился новый отдел — не пересчитываете бюджет.

### Разные отделы — разные базы

В Confluence это spaces. Работает, но всё в одной системе, один админ, одни правила.

**trip2g: отдельные хранилища**

Каждый отдел ведёт свою базу в своём Obsidian-хранилище. Маркетинг — свои заметки. Разработка — свои. HR — свои.

Нужно объединить для поиска? [MCP-сервер](/docs/mcp) сливает несколько баз в один источник знаний. AI отвечает по всем сразу, но каждая команда работает автономно.

### Документация из кода

Разработчики пишут README и docs в репозиториях. В Confluence это копипаст или сложные интеграции.

**trip2g: пуш через CLI**

```bash
trip2g push ./docs --vault=dev-docs
```

Markdown из репозитория улетает в базу знаний. Можно в CI/CD — документация обновляется вместе с кодом. Без ручного копирования, без рассинхрона.

### Работа с контентом

**Confluence:**
- Редактор в браузере — медленнее десктопа
- Нет оффлайн-режима
- Поиск по всему workspace — шум от чужих spaces
- Экспорт — PDF или Word, не markdown

**trip2g:**
- Obsidian — быстрый десктопный редактор
- Полный оффлайн, синхронизация при подключении
- Каждая база — отдельное хранилище, свой поиск
- Исходники всегда в markdown — забрать за минуту

### AI-интеграция

Confluence добавляет AI-фичи, но они работают внутри системы. Подключить к своим инструментам — отдельная задача.

**trip2g: MCP из коробки**

Подключаете базу к Claude, Cursor, любому MCP-клиенту. AI отвечает по вашим знаниям. Можно объединить несколько баз разных отделов — единый корпоративный мозг.

### Когда Confluence всё-таки подходит

- Уже используете Jira и нужна интеграция
- Нужны встроенные workflows и approvals
- Компания платит за Atlassian Cloud целиком
- Все привыкли, переучивать дорого
