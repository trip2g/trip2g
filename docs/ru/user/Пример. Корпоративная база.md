Приватная википедия для сотрудников компании. Знания хранятся в одном месте, доступ контролируется.

### Как это работает

**Структура:**
- База знаний ведётся в Obsidian
- Заметки связаны между собой ссылками
- Сотрудники читают через сайт

**Что можно хранить:**
- Инструкции и регламенты
- Описания процессов
- Ответы на частые вопросы
- Онбординг для новых сотрудников

### Способы выдачи доступа

**По email:**
- Сотрудник входит через рабочую почту
- Доступ привязан к конкретным адресам

**По паролю:**
- Общий пароль для команды или отдела
- Простой способ для небольших групп

**По членству в Telegram группе:**
- Рабочая группа в Telegram
- Бот проверяет, состоит ли пользователь в группе
- Если да — открывает доступ к базе

### Что получает компания

- Знания не теряются при уходе сотрудников
- Новички быстрее вливаются — всё описано
- Меньше повторяющихся вопросов — есть где посмотреть
- Контроль доступа — только свои видят внутреннюю информацию
