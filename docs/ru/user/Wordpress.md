«Друг поставил WordPress, сделал визитку за вечер — всё работает». Да, для визитки WordPress подходит. Но база знаний — не визитка.

### Два разных подхода

**WordPress: сначала сайт, потом контент**

Выбираете тему, настраиваете меню, создаёте страницы. Потом заполняете их текстом. Структура сайта диктует, как писать. Хотите добавить связь между статьями — ставите плагин, настраиваете, надеетесь что не сломается после обновления.

**trip2g: сначала контент, потом сайт**

Пишете заметки в Obsidian. Связываете их между собой. Структура растёт органически — из ваших мыслей, а не из шаблона темы. Когда материал готов — публикуете. Сайт подстраивается под контент, а не наоборот.

### Почему это важно

Эксперт думает не страницами, а связями. Одна идея ведёт к другой. В Obsidian это естественно: `[[ссылка]]` — и заметки связаны. В WordPress каждая связь — ручная работа: найти URL, вставить, проверить.

Когда пишешь в Obsidian — думаешь о содержании. Когда пишешь в WordPress — думаешь о том, как это будет выглядеть, в какую рубрику положить, какой шаблон выбрать.

### Практические проблемы WordPress

**Контент заперт в базе данных:**
- Нельзя работать оффлайн — нужен интернет для любых правок
- Нельзя открыть в любимом редакторе
- Решили переехать — экспорт, конвертация, проверка, боль

**Нет связей из коробки:**
- Backlinks, граф, wikilinks — всё через плагины
- Плагины ломаются, конфликтуют, перестают поддерживаться
- Каждое обновление WordPress — лотерея

**Плохо работает с AI:**
- Нельзя редактировать сайт через Claude или Cursor — контент в базе, не в файлах
- Чтобы AI мог отвечать на вопросы по вашему сайту — нужны отдельные инструменты, интеграции, настройка
- Структура плагинов и тем непредсказуема для AI-агентов

trip2g даёт готовый набор: [MCP-сервер](/docs/mcp) для работы с AI, Telegram-публикация, гибкий доступ к контенту — платный, по коду, по email для конкретных людей. Всё заточено под экспертный контент.

### Когда WordPress всё-таки подходит

- Нужен интернет-магазин (WooCommerce)
- Нужен форум или LMS с готовыми плагинами
- Уже есть сайт на WordPress и команда для поддержки
- Визитка на три страницы
