Telegram поддерживает кастомные эмодзи — анимированные и статичные картинки из стикерпаков. Они ярче и выразительнее обычных emoji.

**Требование:** публикация через [[Публикация через аккаунты|Premium аккаунт]]. Боты не умеют отправлять кастомные эмодзи.

### Как получить код для вставки

Напишите боту [@trip2g_emoji_bot](https://t.me/trip2g_emoji_bot):
- Отправьте сообщение с нужным emoji
- Бот вернёт готовый markdown

```
![emoji](https://ce.trip2g.com/5373112999076699207.webp)
```

Вставьте этот код в заметку.

### Как это работает

**В Obsidian:**
- Emoji отображается прямо в редакторе
- Анимированные emoji тоже работают
- Размер автоматически подгоняется под текст

**При публикации:**
- Сервис преобразует ссылку в формат Telegram
- В канале появится настоящий кастомный emoji

### Ограничения

- Работает только при публикации через Premium аккаунт
- Если опубликовать через бота — emoji не отобразится
