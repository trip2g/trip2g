Плагины расширяют возможности Obsidian под ваши задачи. Добавляйте поддержку новых форматов файлов, интегрируйте сторонние сервисы, автоматизируйте рутину.

Сообщество Obsidian создало тысячи плагинов — от простых до сложных. Вы можете установить готовые или написать свои.

### Безопасность плагинов

Плагины запускают код сторонних разработчиков на вашем компьютере. Теоретически это может быть опасно.

Команда Obsidian проверяет каждый плагин перед публикацией в каталоге. Но полную безопасность не гарантирует никто — устанавливайте только те плагины, которым доверяете.

Подробнее о безопасности читайте в [официальной документации](https://help.obsidian.md/Extending+Obsidian/Plugin+security).

### Как найти плагины

**В приложении Obsidian:**
1. Откройте «Настройки» (Settings)
2. Перейдите в «Community plugins»
3. Нажмите «Turn on community plugins» (если появится предупреждение о безопасности)
4. Нажмите «Browse»
5. Используйте поиск — фильтр работает по названию, автору и описанию

**В браузере:**
Откройте [obsidian.md/plugins](https://obsidian.md/plugins) — там весь каталог с описаниями и скриншотами.

### Как установить плагин

Перед установкой нужно отключить Restricted Mode (режим ограничений).

1. Откройте «Настройки» (Settings)
2. Перейдите в «Community plugins»
3. Нажмите «Browse»
4. Найдите нужный плагин
5. Нажмите «Install»
6. Нажмите «Enable» чтобы включить плагин

После установки плагин появится в списке «Installed plugins».

### Как включить установленный плагин

Установленные плагины по умолчанию выключены. Чтобы включить:

1. Откройте «Настройки» (Settings)
2. Перейдите в «Community plugins» → «Installed plugins»
3. Найдите нужный плагин
4. Переключите тумблер в положение «Enable»

Или нажмите «Enable» сразу после установки — это быстрее.

### Как обновить плагины

Плагины не обновляются автоматически — это сделано для безопасности. Вы контролируете, когда обновлять.

**Обновить все плагины:**
1. Откройте «Настройки» (Settings)
2. Перейдите в «Community plugins» → «Current plugins»
3. Нажмите «Check for updates»
4. Если есть обновления — нажмите «Update all»

**Обновить один плагин:**
1. Откройте «Настройки» (Settings)
2. Перейдите в «Community plugins» → «Current plugins»
3. Нажмите «Check for updates»
4. В списке «Installed plugins» найдите нужный плагин
5. Нажмите «Update» рядом с ним

### Полезные плагины для начала

**Dataview** — превращает ваши заметки в базу данных. Создавайте таблицы, списки, графики на основе метаданных.

**Templater** — продвинутые шаблоны с переменными, датами, скриптами. Автоматизирует создание заметок.

**Calendar** — добавляет календарь для ежедневных заметок. Удобно для дневников и планирования.

**Kanban** — доски в стиле Trello прямо в Obsidian. Для управления проектами и задачами.

**Advanced Tables** — упрощает работу с таблицами в Markdown. Автоформатирование, навигация клавишами.
