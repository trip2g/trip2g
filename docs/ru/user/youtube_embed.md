---
title: Встраивание YouTube видео
---

Добавьте видео в заметку — посетители смотрят его прямо на странице.

## Как добавить видео

Используйте синтаксис изображения с ссылкой на YouTube:

```markdown
![](https://www.youtube.com/watch?v=VIDEO_ID)
```

Где `VIDEO_ID` — это идентификатор видео из URL.

## Примеры

### Полная ссылка YouTube

```markdown
![](https://www.youtube.com/watch?v=dQw4w9WgXcQ)
```

### Короткая ссылка youtu.be

```markdown
![](https://youtu.be/dQw4w9WgXcQ)
```

Оба варианта работают одинаково.

## Где взять ссылку на видео

1. Откройте видео на YouTube
2. Скопируйте ссылку из адресной строки браузера
3. Вставьте её в заметку в формате `![](ссылка)`

Или нажмите кнопку "Поделиться" под видео и скопируйте короткую ссылку.

## Пример заметки

```markdown
---
free: true
title: Обзор нового продукта
---

Рассказываю о новом продукте.

## Видео-обзор

![](https://www.youtube.com/watch?v=dQw4w9WgXcQ)

Полный обзор — в видео.
```

## Результат

Плеер адаптивный:
- Автоматически подстраивается под ширину страницы
- Поддерживает полноэкранный режим
- Работает на мобильных устройствах
