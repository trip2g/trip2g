Панель управления отвечает за всё, кроме заметок: читатели и их доступы, Telegram-боты, платежи, API-ключи, редиректы и состояние системы. Она открывается по адресу `/_system/admin` — или по шестерёнке в верхней панели после входа под администратором. На свежем инстансе нужны три места: **Dashboard** (убедиться, что первая синхронизация прошла), **Интеграции → API ключи** (ключи для плагина синхронизации и AI-агентов) и **Telegram → TG боты** (если публикуете в канал). Остальное подождёт, пока не понадобится.

Разделы ниже — в том порядке, в котором их показывает панель.

### Dashboard

Стартовая страница панели. Один взгляд отвечает на вопрос «сайт жив и актуален?»:

- **Версия и документация** — версия софта на вашем инстансе и ссылка на эту документацию.
- **Занятое место** — сколько занимают база данных и файлы заметок.
- **Предупреждения в заметках** — заметки, которые отрендерились с проблемами (битые ссылки, ошибки в frontmatter). Проверяйте после больших синхронизаций.
- **Недавно изменённые заметки** — последние изменения с постоянными ссылками; так удобно убедиться, что синхронизация дошла.

В тулбаре — два ярлыка: [[ru/user/editor|редактор файлов в браузере]] и [[ru/user/Browser Sync]].

### Пользователи

Ваши читатели: кто они и что им можно читать. Управление скриптами через GraphQL описано в [[ru/user/user_management|Управлении пользователями]].

- **Пользователи** — все аккаунты читателей. Добавьте пользователя вручную, откройте карточку, забаньте.
- **Баны** — список заблокированных аккаунтов.
- **Доступы к подграфам** — доступ к закрытым [[ru/user/subgraphs|подграфам]], выданный вручную. Здесь вы открываете читателю доступ без покупки.
- **Запросы в очередь по email** — адреса, которые читатели оставили на пейволле с листом ожидания, с датой и IP.
- **Запросы в очередь по Telegram** — те же запросы, пришедшие через Telegram-бота.

### Заметки и контент

Опубликованное хранилище глазами сервера. Заметки вы редактируете в Obsidian; этот раздел показывает, что из них получилось.

- **Подграфы** — группы доступа, к которым относятся заметки. Смотрите [[ru/user/subgraphs|Подграфы]].
- **Просмотры заметок** — каждая опубликованная заметка: постоянная ссылка, путь, название, флаг free. Самый быстрый способ ответить «эта заметка опубликована и открыта?»
- **Файлы в заметках** — картинки и файлы, прикреплённые к заметкам.
- **Note Graph** — визуальный граф связей между опубликованными заметками.
- **Layout Editor** — редактируйте шаблоны страниц в браузере: список блоков и живое превью. Смотрите [[ru/user/templates|Шаблоны]].
- **Патчи метаданных** — серверные правки свойств заметок, которые переживают повторную синхронизацию. Смотрите [[ru/user/frontmatter_patches|Frontmatter-патчи]].
- **Form Notes** — заметки с формами и собранные ими отправки. Смотрите [[ru/user/forms|Формы в заметках]].

### Telegram

Публикация в каналы и доступ через группы. Подробный разбор — в статье [[ru/user/telegram|Telegram]].

- **TG боты** — подключите бота: он публикует заметки в канал, авторизует читателей и охраняет [[ru/user/telegram-access|доступ через группу]].
- **Telegram аккаунты** — публикация от имени обычного аккаунта вместо бота: снимает ограничения Bot API на медиа и кастомные эмодзи. Смотрите [[ru/user/Публикация через аккаунты|Публикацию через аккаунты]].
- **Telegram посты** — очередь публикации: какие заметки запланированы, какие отправлены. «Send Now» отправляет пост немедленно, «Reset» возвращает его в очередь.

### Монетизация

Продажа доступа к закрытым заметкам. Подробный разбор — в статье [[ru/user/monetization|Монетизация]].

- **Предложения** — то, что вы продаёте: предложение открывает подграф за указанную цену.
- **Покупки** — записи о платежах: email покупателя, платёжный провайдер, статус.
- **Учетные данные Patreon** — подключите Patreon; уровни и подписчики синхронизируются, патроны получают доступ автоматически.
- **Учетные данные Boosty** — то же самое для Boosty.

### Интеграции

Ключи и учётные данные, которые связывают внешний мир с вашим инстансом.

- **API ключи** — ключи для плагина синхронизации Obsidian, [[ru/user/mcp|MCP-сервера]] и GraphQL API. Первое, что создают на новом инстансе — если [[ru/user/onboarding-vault|стартовый архив]] не сделал это за вас.
- **Git токены** — токены для [[ru/user/git|доступа к контенту по Git]].
- **Google OAuth** / **GitHub OAuth** — вход читателей через Google или GitHub. Смотрите [[ru/user/oauth|OAuth авторизацию]].
- **Federation Secrets** — входящие и исходящие секреты для [[ru/user/federation|MCP Federation]] между инстансами.

### SEO и URL

Порядок в адресах после переездов и переименований. Смотрите [[ru/user/seo|SEO]].

- **Перенаправления** — 301-редиректы со старых адресов на новые. Обязательны при переезде с другой платформы.
- **Не найденные пути** — журнал адресов, по которым посетители получили 404. Настоящие адреса из него переносите в перенаправления.
- **Игнорируемые шаблоны 404** — шаблоны (шум ботов, сканеры), которые не попадают в журнал 404.
- **HTML вставки** — HTML-фрагменты, которые вставляются в `<head>` или в конец `<body>` каждой страницы: счётчики аналитики, теги верификации. Вставке можно задать период действия.

### Система

Машинное отделение. Сюда заходят, когда что-то выглядит не так — или когда настраивают автоматизацию.

- **Задачи cron** — встроенные задачи по расписанию; каждую можно запустить вручную.
- **Фоновые очереди** — очереди задач синхронизации и публикации; очередь можно остановить, запустить или очистить.
- **Настройки сайта** — настройки инстанса в виде записей конфигурации: кто и когда что менял.
- **Состояние системы** — статус подсистем инстанса.
- **Браузерная синхронизация** — синхронизируйте папку хранилища прямо из браузера, без Obsidian. Смотрите [[ru/user/Browser Sync]].
- **Релизы** — публикация замороженных снимков сайта. Смотрите [[ru/user/releases|Релизы]].
- **Администраторы** — выдача прав администратора другим пользователям.
- **Журнал аудита** — журнал заметных событий на инстансе с отметками времени.
- **Вебхуки изменений** — вызов внешних URL при изменении заметок. Смотрите [[ru/user/change_webhooks|Вебхуки при изменении заметок]].
- **Крон-вебхуки** — вызов внешних URL по расписанию. Смотрите [[ru/user/cron_webhooks|Вебхуки по расписанию]].
