Скройте часть заметок за пейволом — подписчики увидят их после авторизации.

### Как работает доступ

Заметка без `free: true` в frontmatter закрыта по умолчанию. Её видят только администраторы и авторизованные подписчики. Все остальные видят превью и форму входа.

В одном хранилище можно держать два уровня контента: публичные заметки с `free: true` и закрытые без него.

### Patreon

Подключите Patreon в настройках. Ваши патроны авторизуются на сайте через Patreon и сразу получают доступ к закрытому контенту — без ручного добавления каждого подписчика.

### Boosty

Работает так же, как Patreon. Подписчики Boosty авторизуются через Boosty и автоматически получают доступ к материалам по активной подписке.

### Криптоплатёж

Принимайте оплату криптовалютой напрямую. После оплаты читатель получает доступ к закрытым заметкам — без посредников и платёжных платформ.

### Telegram-группа

Подключите хранилище к платной Telegram-группе:

1. Добавьте бота в группу как администратора.
2. В настройках подключите группу к боту.
3. Бот проверяет членство посетителя в группе.
4. Участники группы получают доступ к закрытому контенту автоматически.

Для приёма платежей используйте любой из популярных ботов для монетизации Telegram-групп — их несколько десятков. trip2g не привязан к конкретному: вы сами выбираете, кого пускать в группу, trip2g видит только факт членства.

### Превью для неавторизованных

Посетитель видит начало заметки до авторизации. Остаток скрыт — до входа с активной подпиской.

### Как подписчики входят

Подписчики входят по ссылке на email (magic link). После входа система проверяет статус подписки через подключённую платформу — Patreon, Boosty, криптоплатёж или членство в Telegram-группе — и открывает или закрывает доступ.
