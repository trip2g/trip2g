Сервис публикует заметки из Obsidian в Telegram. Вы пишете в markdown, а сервис превращает это в разметку Telegram.

### Типы постов

#### Пост с текстом
- Обычный текст
- Ограничение: 4096 символов
- Если текст длиннее — сервис не опубликует заметку

#### Пост с одной фотографией
- Одна картинка с подписью
- Ограничение для подписи: 1024 символа

#### Альбом
- Несколько фотографий в одном посте
- Ограничение для подписи: 1024 символа

Если текст длиннее лимита, то система не сможет его опубликовать.

### Форматирование текста

#### Жирный текст
```
**жирный текст**
```

#### Курсив
```
*курсив*
```

#### Зачеркнутый
```
~~зачеркнутый~~
```

#### Моноширинный
```
`код`
```

#### Подчеркнутый
```html
<u>подчеркнутый</u>
```

#### Спойлер
```
==спойлер==
```
→ скрытый текст, который раскрывается по клику

#### Комбинации
```
***жирный курсив***
**_жирный курсив_**
```

### Ссылки

#### Обычная ссылка
```
[текст ссылки](https://example.com)
```

#### Wiki-ссылка на опубликованную заметку
```
[[название-заметки]]
```
→ превращается в ссылку на вашу заметку

#### Wiki-ссылка с другим текстом
```
[[название-заметки|с другим названием]]
```
→ ссылка будет вести на заметку, но текст будет «с другим названием»

#### Wiki-ссылка на неопубликованную заметку
```
[[название-заметки]]
```
→ превращается в <u>подчеркнутый текст</u>

Если у неопубликованной заметки указана дата публикации, сервис добавит в конец поста блок:

```
—————————
🔜 Скоро выйдут:
• Название заметки — 15 ноября, 14:30

📬 Подпишитесь, чтобы не пропустить
```

### Блоки кода

#### Код с подсветкой синтаксиса
````
```python
def hello():
    print("Hello, world!")
```
````

#### Код без подсветки
````
```
обычный код
без подсветки
```
````

Поддерживаются все языки, которые знает Telegram.

### Цитаты

#### Обычная цитата
```
> Это цитата
> Может быть многострочной
```

#### Раскрывающаяся цитата
```
> Это цитата||
```
→ цитата со стрелочкой, раскрывается по клику

Чтобы сделать цитату раскрывающейся, добавьте `||` в конец. Telegram покажет её свернутой, пользователь сможет раскрыть.

### Списки

#### Маркированный список
```
- Первый пункт
- Второй пункт
- Третий пункт
```

#### Нумерованный список
```
1. Первый пункт
2. Второй пункт
3. Третий пункт
```

Нумерация в Telegram будет правильной, даже если вы используете везде `1.`

### Что не поддерживается

Сервис покажет предупреждение, если встретит:
- Обычные изображения (не emoji)
- Неизвестные HTML-теги (кроме `<u>`)
- Неизвестные элементы разметки

Заметки с неподдерживаемыми элементами не будут опубликованы. В списке на публикацию вы увидите предупреждение.
