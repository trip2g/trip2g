Бесплатный статический генератор сайтов для публикации Obsidian-заметок. Мощный инструмент, но требует технических знаний.

### Что умеет

- Полная кастомизация через код
- Бесплатный хостинг на GitHub Pages
- Граф связей, поиск, backlinks
- Никаких ограничений — это ваш код

### Сложности

**Нужны технические навыки:**
- Работа с командной строкой (терминал)
- Базовое понимание Git и GitHub
- Умение разбираться в конфигурационных файлах

**Много шагов настройки:**
- Клонирование репозитория
- Настройка GitHub Pages
- Установка плагинов Obsidian для синхронизации
- Конфигурация под свои нужды

**Нет готовой инфраструктуры:**
- Нет админки
- Нет управления доступом
- Нет интеграции с Telegram
- Каждое изменение требует пересборки сайта

### Когда подходит

- Есть технические навыки или человек, который настроит
- Нужен полный контроль над кодом
- Устраивает статический сайт без динамики
