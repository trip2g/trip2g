RSS — это заметка. Добавьте заметку с frontmatter `layout: rss`, и она рендерится в RSS 2.0-фид ваших остальных заметок.

## Настройка

Создайте заметку (например `feed.md`) с:

```yaml
---
slug: /feed.xml
content_type: application/rss+xml; charset=utf-8
layout: rss
free: true
rss_glob: "**"
rss_limit: 20
---
```

Готово — откройте `/feed.xml` и увидите фид. В него попадают только публично читаемые заметки (free, без sign-in-гейта, без системных).

| Поле | Что делает | По умолчанию |
|------|------------|--------------|
| `rss_glob` | Какие заметки включать (glob, например `"blog/**"`) | `**` (все) |
| `rss_limit` | Максимум элементов | `20` |
| `rss_title` | Заголовок фида | Заголовок заметки |
| `rss_description` | Описание фида | Описание заметки |

## Кастомизация фида

Фид рендерится через `_layouts/rss.html` — обычный Jet-layout. Отредактируйте его (или укажите свой в `layout:`), чтобы изменить набор полей элемента или сделать несколько фидов с разным охватом (например `/blog-feed.xml` с `rss_glob: "blog/**"`).

## Миграция со старого `.rss.xml`

Старый автоматический фид `<адрес-заметки>.rss.xml` (по фиду на заметку, элементы = ссылки внутри неё) убран. Старые ссылки подписчиков такого вида теперь отдают 404 — редиректа нет. Настройте `/feed.xml` как описано выше.
