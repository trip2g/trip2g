Любая страница вашего сайта может стать RSS-лентой. Ссылки внутри заметки автоматически превращаются в элементы фида.

## Зачем это нужно

Вы ведёте подборку статей, книг или ресурсов. Читатели хотят узнавать о новых добавлениях, но не готовы проверять страницу каждый день.

RSS решает эту проблему: читатель подписывается один раз — и получает обновления в своём RSS-ридере.

Без RSS: читатели забывают о вашей подборке и перестают заходить.
С RSS: каждое новое добавление приходит им автоматически.

## Что получит пользователь

**Владелец сайта:**
- Подписчики не теряются — они получают обновления
- Не нужно создавать отдельный фид — он генерируется из существующей страницы
- Настройка за минуту — добавьте `.rss.xml` к адресу страницы

**Читатели сайта:**
- Подписка на любую страницу с подборками
- Уведомления о новых материалах в привычном RSS-ридере

## Живая база знаний

Заметка — не статичная публикация, а развивающийся документ. Вы добавляете ссылки, подписчики видят обновления. База знаний становится живой.

**Куратор по теме**
Собираете ссылки по теме в одной заметке. Добавили новую статью — подписчики узнали.

**Сейчас читаю**
Список книг и статей, который пополняется. Подписчики следят за вашими находками в реальном времени.

**Рабочий журнал**
Ведёте daily notes со ссылками на задачи и материалы. Коллеги подписываются и видят, над чем вы работаете.

**Roadmap проекта**
Добавляете ссылки на реализованные фичи. Пользователи подписываются на прогресс.

**Changelog**
Каждый релиз — ссылка на заметку с описанием. История изменений в виде RSS-ленты.

## Как это работает

Вы добавляете `.rss.xml` к адресу любой заметки — и получаете готовую RSS-ленту.

Пример: страница `/reading` превращается в фид `/reading.rss.xml`

Каждая ссылка на странице становится элементом ленты:
- Текст ссылки → заголовок элемента
- URL ссылки → адрес элемента
- Если ссылка ведёт на вашу заметку — подтягиваются её описание и дата создания

Порядок элементов в фиде совпадает с порядком ссылок на странице.

## Как настроить

### Базовое использование

Ничего настраивать не нужно. Добавьте `.rss.xml` к адресу страницы:

```
https://ваш-сайт.ru/подборка → https://ваш-сайт.ru/подборка.rss.xml
```

### Кастомизация заголовка и описания

По умолчанию заголовок и описание фида берутся из заметки. Чтобы задать свои, добавьте в frontmatter:

```yaml
---
rss_title: "Мои рекомендации"
rss_description: "Статьи и книги, которые стоит прочитать"
---
```

| Поле | Что делает | По умолчанию |
|------|------------|--------------|
| `rss_title` | Заголовок RSS-канала | Заголовок заметки |
| `rss_description` | Описание RSS-канала | Описание заметки |

### Отключение RSS

Если не хотите генерировать RSS-ленты, отключите функцию в настройках сайта через `enable_rss = false`.

## Что может пойти не так

**Фид пустой**
Проверьте, есть ли на странице ссылки. Изображения и медиафайлы не попадают в RSS — только текстовые ссылки.

**Нет описаний у элементов**
Описания подтягиваются только для внутренних ссылок (на ваши заметки). Для внешних ссылок описание будет пустым.

**Нет дат публикации**
Даты берутся из поля `created_at` целевой заметки. Если дата не указана — элемент будет без даты.
