title: Obsidian Publish
---
Официальный сервис от команды Obsidian для публикации заметок. Простой в использовании, но с ограничениями.

### Что умеет

- Публикация заметок одной кнопкой
- Граф связей между заметками
- Поиск по сайту
- Несколько тем оформления

### Ограничения

**Нет полной кастомизации:**
Нельзя использовать свои шаблоны. Например, сайт trip2g.com, где опубликована эта документация, сделан через собственные шаблоны — в Obsidian Publish так не получится.

**Ограниченный контроль доступа:**
Можно закрыть весь сайт паролем. Нельзя открыть часть материалов бесплатно, а часть — по подписке.

**Нет сторонних скриптов:**
Нельзя подключить Яндекс Метрику, Google Analytics или другие инструменты аналитики.

**Нет SEO-оптимизации:**
Ограниченные возможности для настройки метатегов и индексации.

**Проблемы с оплатой из РФ:**
Сервис принимает оплату через Stripe. Российские карты могут не работать.

### Когда подходит

- Нужен простой сайт без кастомизации
- Не важна аналитика
- Нет проблем с оплатой зарубежных сервисов
