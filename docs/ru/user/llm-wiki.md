Вики — это артефакт, а не чат. Trip2G превращает markdown-базу знаний в MCP-доступный артефакт, который агенты — Claude, Cursor, Codex и другие — могут читать, обходить и пополнять.

Агенты часто заново открывают один и тот же контекст в каждой сессии. RAG извлекает фрагменты, но полезный синтез исчезает обратно в чат. LLM Wiki сохраняет синтез как долгосрочный артефакт — растущую базу знаний, по которой агент может навигировать, а не только делать запросы.

### Чем LLM Wiki отличается от чата и RAG

|  | Чат | RAG | LLM Wiki |
|---|---|---|---|
| Хранит синтез | Нет | Нет | Да |
| Навигация агента | Нет | Частично | Да |
| Накапливается | Нет | С усилием | Встроено |
| Инструкции агенту | Нет | Нет | Да |
| Провенанс | Нет | Частично | Да |

Trip2G — операционный слой:

- **Markdown-хранилище** — заметки Obsidian, опубликованные как сайт
- **MCP-доступ** — `search()`, `note_html()`, `instructions()` для любого MCP-клиента
- **Страницы-инструкции** — `AGENTS.md`, `SCHEMA.md`, `_mcp_initialize.md` как вызываемые MCP-методы
- **Index-first навигация** — агент идёт от `index.md` по вики-ссылкам
- **Поиск/RAG** — векторный поиск для больших или менее структурированных баз
- **Федерация** — базы знаний могут ссылаться друг на друга

### Быстрый старт за 10 минут

**1.** Создайте бесплатный инстанс на trip2g.com и установите плагин синхронизации Obsidian.

**2.** Создайте структуру папок в хранилище (см. ниже) или скачайте стартовый шаблон.

**3.** Добавьте первый источник — вставьте любой markdown-контент в `raw/`.

**4.** Заполните `index.md` — о чём эта база, `AGENTS.md` — инструкции агенту, `SCHEMA.md` — структура страниц.

**5.** Синхронизируйте хранилище и включите MCP-сервер в настройках сайта.

**6.** Подключите MCP-эндпоинт к агенту (Claude Desktop, Claude Code, Cursor и т.д.).

**7.** Спросите: *«Прочитай index.md и объясни, что знает эта база.»*

### Два режима чтения базы агентом

Агент может работать с LLM Wiki двумя способами. Режим обычно описан в `AGENTS.md`.

#### Режим A — Index-first обход

Подходит для структурированных или небольших баз с чёткой иерархией.

```
Вопрос
→ читаем index.md
→ открываем нужные страницы
→ следуем по вики-ссылкам
→ отвечаем с цитатами
```

Агент обходит граф так же, как это делает человек. Хорошо работает для баз концептов, логов решений и исследовательских заметок.

#### Режим B — Поиск/RAG-ассистированное извлечение

Подходит для больших или менее структурированных баз.

```
Вопрос
→ search(query)
→ смотрим совпадения и TOC
→ note_html() для загрузки раздела
→ следуем по вики-ссылкам
→ проверяем источники
→ отвечаем
```

RAG извлекает фрагменты. LLM Wiki накапливает синтез. Используйте оба подхода когда нужно — база растёт из синтеза каждой сессии, делая следующие запросы точнее.

### Страницы-инструкции

Trip2G превращает заметки с frontmatter `mcp_method` в вызываемые MCP-инструменты. Три стандартные страницы:

**`AGENTS.md`** — как агенту работать с этой базой:

```yaml
---
free: true
mcp_method: instructions
mcp_description: "How agents should use this knowledge base."
---

# Роль
Отвечай на вопросы только на основе этой базы знаний.

## Рабочий процесс
1. search(query) — найти нужные заметки
2. note_html() — загрузить заметку или раздел через toc_path
3. Следовать по вики-ссылкам к связанным заметкам
4. Отвечать с цитатами
```

**`SCHEMA.md`** — типы страниц, frontmatter и правила обновления:

```yaml
---
free: true
mcp_method: schema
mcp_description: "Page types, frontmatter and update rules for this LLM Wiki."
---

# Схема

## Типы страниц
- concepts/    — определения, одна концепция на страницу
- sources/     — источники с провенансом
- decisions/   — принятые решения, обоснование, дата
- queries/     — заданные вопросы и найденные ответы
- comparisons/ — таблицы сравнения
```

**`_mcp_initialize.md`** (опционально) — инициализация сессии:

```yaml
---
free: true
mcp_method: initialize
mcp_description: "Start a session with this knowledge base."
---

1. Прочитать index.md, чтобы понять область знаний
2. Прочитать SCHEMA.md, чтобы понять структуру
3. Сообщить, по каким вопросам готов помочь
```

### Стартовая структура папок

```
llm-wiki/
├── _index.md           — главная страница сайта (trip2g)
├── AGENTS.md           — инструкции агенту  (mcp_method: instructions)
├── SCHEMA.md           — структура и правила обновлений  (mcp_method: schema)
├── _mcp_initialize.md  — инициализация сессии, опционально  (mcp_method: initialize)
├── index.md            — что знает эта база (человекочитаемое оглавление)
├── log.md              — лог сессий, синтез, открытые вопросы
├── raw/                — необработанные источники, транскрипты, черновики
├── sources/            — обработанные источники с провенансом
├── concepts/           — ключевые концепты и определения
├── queries/            — вопросы и найденные ответы
├── comparisons/        — страницы со структурированными сравнениями
└── decisions/          — решения с обоснованием и датой
```

`index.md` и `log.md` — два важнейших файла. `index.md` говорит агенту, что существует; `log.md` накапливает синтез, который иначе исчезал бы в чате.

### Федерация

База знаний может ссылаться на другие базы. KB-заметка в хранилище регистрирует пира; агент охватывает его через `federated_search`. Несколько тематических баз можно объединить в один хаб, с которым агент работает через один MCP-эндпоинт.

→ См. [[ru/user/federation|MCP Federation]]
