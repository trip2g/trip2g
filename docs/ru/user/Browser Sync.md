Browser Sync публикует заметки из локальной папки на сайт прямо из браузера — без плагина, без CLI, без API-ключа. Откройте страницу администратора, выберите папку и нажмите «Upload».

### Как использовать

1. Перейдите в Администратор → System → Browser Sync.
2. Нажмите **Select folder**, выберите папку с заметками и разрешите доступ, когда браузер спросит.
3. Страница покажет «Will upload N file(s)» и список файлов — это предпросмотр, ничего ещё не отправлено.
4. Нажмите **Upload**, чтобы опубликовать файлы на сайте.

Готово. Файлы появятся на сайте сразу.

### Как поддерживать сайт актуальным

После редактирования файлов на диске нажмите **Refresh** — страница пересчитает файлы в папке и покажет актуальный список. Browser Sync не следит за файловой системой самостоятельно.

Для автоматической работы включите **Auto-sync (every 30s)**. Страница будет сама проверять папку и загружать изменения каждые 30 секунд — пока вкладка браузера открыта.

Выбранная папка запоминается в браузере и восстанавливается при следующей загрузке страницы: повторно выбирать не нужно. Настройка привязана к конкретному браузеру и устройству.

Нажмите **Clear folder**, чтобы забыть выбранную папку.

### Авторизация

Browser Sync использует вашу текущую сессию администратора. Дополнительная настройка не нужна.

### Ограничения

**Только загрузка.** Browser Sync работает в одну сторону: локальная папка → сайт. Изменения с сайта в папку не возвращаются. Для двусторонней синхронизации или фоновой работы без открытой вкладки используйте [[ru/user/Двухсторонняя синхронизация|плагин trip2g sync для Obsidian]].

**Только десктопный Chrome и Edge.** Browser Sync использует браузерный File System Access API, недоступный в Firefox, Safari и мобильных браузерах.

**Не фоновый сервис.** Автосинхронизация работает только пока вкладка администратора открыта. Браузеры ограничивают фоновые вкладки, поэтому закрытие или сворачивание окна прерывает синхронизацию. Для непрерывной работы используйте плагин Obsidian или CLI синхронизации.

### Когда использовать Browser Sync

Browser Sync — самый быстрый способ попробовать trip2g без установки чего-либо. Выберите папку, и заметки окажутся на сайте за секунды.

Для ежедневной публикации используйте [[ru/user/Двухсторонняя синхронизация|плагин trip2g sync для Obsidian]]: он работает в фоне, поддерживает двустороннюю синхронизацию и не требует открытой вкладки.
