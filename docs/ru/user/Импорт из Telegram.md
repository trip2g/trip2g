Сервис умеет импортировать посты из Telegram канала и превращать их в заметки. Это позволяет перенести весь архив канала в Obsidian.

### Что импортируется

**Текст:**
- Форматирование сохраняется (жирный, курсив, ссылки)
- Кастомные эмодзи преобразуются в формат для Obsidian

**Медиа:**
- Фотографии скачиваются и добавляются к заметке
- Видео скачиваются и добавляются как ссылки

**Ссылки между постами:**
- Ссылки на другие посты канала превращаются в wikilinks
- Работает в обе стороны — пост может ссылаться на более поздний пост

### Как это работает

**Название заметки:**
- Берётся из первых 7 слов поста
- Эмодзи и форматирование убираются
- Если название совпадает с другим постом — добавляется ID сообщения

**Метаданные:**
- `telegram_publish_channel_id` — ID канала
- `telegram_publish_message_id` — ID сообщения
- `telegram_publish_at` — дата публикации

**Повторный импорт:**
- Уже импортированные посты пропускаются
- Если удалить заметку — при следующем импорте она появится снова
- Можно запускать импорт несколько раз — новые посты добавятся к существующим

### Ограничения

- Импорт работает только через подключённый Telegram аккаунт
- Аккаунт должен иметь доступ к каналу
- Импорт больших каналов занимает время — процесс идёт в фоне
