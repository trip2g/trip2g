**Коротко:** прочитать только секцию с ответом стоит во много раз дешевле, чем вывалить всю заметку — здесь примерно в **15× меньше** (медиана). Агент попадает в эту секцию детерминированно (матч из search указывает прямо на неё), поэтому один и тот же вопрос всегда читает одну и ту же секцию.

Числа живые. Мы задали MCP-серверу trip2g настоящие вопросы и сравнили два способа, которыми агент читает ответ: вывалить **всю заметку** или достать только **нужную секцию**. Разница — это и есть экономия токенов.

```datachart
{
  "data": { "source": "frontmatter", "ref": "chart" },
  "config": {
    "title": { "text": "Токенов на чтение ответа (меньше — лучше)" },
    "tooltip": { "trigger": "axis" },
    "legend": {},
    "xAxis": { "type": "category", "name": "вопрос" },
    "yAxis": { "type": "log", "name": "токены (прибл.)" },
    "series": [
      { "type": "bar", "name": "вся заметка", "encode": { "x": "query", "y": "whole_note" } },
      { "type": "bar", "name": "нужная секция", "encode": { "x": "query", "y": "focused_read" } }
    ]
  }
}
```

На этих вопросах чтение нужной секции стоит примерно в **15× меньше токенов** (медиана), чем вывалить всю заметку. Выигрыш растёт с размером заметки: длинные (вебхуки, мультиязычность) экономят больше всего, короткие (подписки) — меньше, маленькая заметка и так дешёвая.

Секция находится детерминированно: результат поиска уже содержит `toc_path`, указывающий прямо на нужный заголовок, поэтому один и тот же вопрос всегда попадает в одну и ту же секцию. Маршрут: `search` → `expand` → `note_html` — обход дерева не нужен, когда указатель из матча уже есть.

Одна честная оговорка. Сэкономить токены — лёгкая половина. Трудная и интересная — **попасть точно в нужную секцию**, и для этого есть оглавление заметки: читаешь верхний уровень, потом проваливаешься вглубь, а не ищешь по всем чанкам. Механизм — в [[Token Economy]] и [[Fuzzy Pointer]].

**Проверь сам.** Без зависимостей, только Python 3:

```sh
python3 scripts/expand_check.py
```

Скрипт задаёт `https://trip2g.com/_system/mcp` те же вопросы и печатает таблицу.
