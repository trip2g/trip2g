**trip2g делает то же самое для Obsidian.**

### Что делает Super.so

Страницы Notion медленные, без своего домена, без аналитики. Super это исправляет:

- Подключает ваш домен
- Ускоряет загрузку в 100 раз
- Добавляет SEO-теги и аналитику
- Даёт готовые темы оформления

Вы работаете в Notion. Super превращает заметки в сайт.

### Чем отличается trip2g

Всё то же — домен, скорость, SEO, темы. Плюс:

**Публикация в Telegram:**
Пост из Obsidian уходит в канал по расписанию.

**Платный контент:**
Часть материалов бесплатно, часть — по подписке.

**Файлы у вас:**
Заметки хранятся на вашем диске, не в облаке.
