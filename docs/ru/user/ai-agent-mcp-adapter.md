Дайте ИИ-агенту вашу базу знаний — и он читает только ту секцию, что отвечает на вопрос, а не всю заметку. Несколько сотен токенов вместо нескольких тысяч, и ответ — в начале контекста, где модель читает его лучше всего.

trip2g говорит на [[mcp|MCP]] (Model Context Protocol). Этот маленький адаптер заворачивает три шага — поиск, навигацию по оглавлению и чтение секции — в **один инструмент**, который вызывает агент. Никаких вываленных целиком заметок и слепого grep.

### Что вы получаете

Один Python-скрипт. **Без зависимостей, без `pip install`** — агент запускает его напрямую. Скачайте на GitHub:

[trip2g_mcp_stdio_adapter.py](https://github.com/trip2g/trip2g/blob/main/docs/en/user/trip2g_mcp_stdio_adapter.py)

### Настройка

1. Скачайте скрипт выше.
2. Добавьте его в свой MCP-клиент (Claude Desktop, Cursor, Claude Code или любой агент с MCP по stdio):

```json
{
  "mcpServers": {
    "trip2g": {
      "command": "python3",
      "args": ["/абсолютный/путь/к/trip2g_mcp_stdio_adapter.py"],
      "env": { "TRIP2G_MCP_URL": "https://ВАШ-САЙТ/_system/mcp" }
    }
  }
}
```

3. Для приватного или платного контента добавьте `"TRIP2G_TOKEN": "t2g_…"` в `env` (токен — в личном кабинете → Токены).

Готово. У агента теперь один инструмент — *найти и прочитать самую релевантную секцию* — с описанием, когда его применять. Задаёте вопрос, получаете ровно нужную секцию, дёшево.

Почему это лучше, чем вываливать заметки целиком: [[Token Economy]].
