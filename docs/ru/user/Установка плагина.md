Плагин trip2g sync связывает Obsidian с вашим сайтом. Заметки из хранилища загружаются на сервер при синхронизации.

Главная ссылка, если знаете, что делать:
`https://github.com/trip2g/obsidian-sync`

### Шаг 1: Установите BRAT

BRAT — плагин для установки бета-версий других плагинов. Плагин trip2g пока не опубликован в официальном каталоге Obsidian.

1. Откройте настройки Obsidian → «Community plugins»
2. Найдите BRAT и установите
3. Включите плагин

Если не знаете, как устанавливать [[community_plugins|плагины от сообщества]] — прочитайте инструкцию.

### Шаг 2: Добавьте плагин trip2g через BRAT

1. Откройте настройки BRAT
2. Нажмите «Add beta plugin»

![[brat_settings.webp]]

3. В поле «Repository» вставьте `https://github.com/trip2g/obsidian-sync`
4. В поле «Version» выберите «Latest»
5. Нажмите «Add plugin»

![[brat_trip2g.webp]]

### Шаг 3: Создайте API ключ

1. Откройте админ-панель вашего сайта
2. Перейдите в «API ключи»
3. Нажмите «+ Add» → «Submit»
4. Скопируйте ключ

### Шаг 4: Подключите плагин к сайту

1. Откройте настройки плагина «trip2g sync»
2. Нажмите «Add sync directory»
3. Вставьте адрес вашего сайта: `https://yourinstance.trip2g.com`
4. Вставьте скопированный API ключ
5. Нажмите «Test All Connections»

Если всё работает — вы увидите зелёную галочку.

![[trip2g_settings.webp]]

### Настройки плагина

**Sync folder (Папка синхронизации)**
Папка в хранилище для синхронизации. Используйте `/` для синхронизации всего хранилища.

**Publish fields (Поля публикации)**
Фильтр по свойствам. Если указать `publish`, синхронизируются только заметки с `publish: true`. Если оставить пустым — синхронизируются все файлы.

### Как синхронизировать

Нажмите кнопку синхронизации на боковой панели или используйте команду «trip2g sync: Sync».

![[sync_button.webp]]
