Опубликуйте хранилище Obsidian как сайт — за минуту.

Пишете в Obsidian, жмёте Sync — заметки уже онлайн. Тот же хаб публикует в Telegram, закрывает платные материалы за пейволом и отвечает на вопросы читателей по MCP. Markdown-операционка: одна заметка — и страница для человека, и системный вызов для агента.

**Впервые здесь?** Пройдите [[ru/user/Начало работы|Начало работы]]: войдите на свой инстанс, скачайте стартовый архив, откройте его в Obsidian и нажмите синхронизацию. Своего инстанса нет — попробуйте бесплатную [[ru/user/cloud|облачную песочницу]].

Ниже — главные страницы по разделам. Полный список — в меню слева.
