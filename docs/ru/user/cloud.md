trip2g Cloud — бесплатная публичная песочница. Один клик, и у вас есть живой сайт без установки сервера.

**[Открыть облако → simplecloud.2pub.me](https://simplecloud.2pub.me)**

Перейдите на [simplecloud.2pub.me](https://simplecloud.2pub.me), войдите в аккаунт, нажмите **Open as Admin**. Вы попадаете в администраторский интерфейс реального работающего сайта на случайно назначенном поддомене — например, `honesthesse.2pub.me`. Дальше всё как с обычным инстансом trip2g: скачайте стартовое хранилище, откройте в Obsidian, нажмите Sync — и сайт обновится.

### Как начать

1. Откройте [simplecloud.2pub.me](https://simplecloud.2pub.me)
2. Войдите по email и паролю (или через GitHub / Google)
3. Нажмите **Open as Admin** на вашем пространстве
4. Скачайте стартовое хранилище со страницы приветствия, откройте его в Obsidian
5. Нажмите Sync — заметки опубликуются на вашем поддомене

Полное описание работы с синхронизацией — в [[ru/user/Начало работы|руководстве по началу работы]].

### Что это такое и чем не является

Это песочница. Без SLA, без резервных копий, работает по возможности. Квота — около 100 МБ на пространство. Не храните здесь то, что нельзя потерять.

Подходит для: знакомства с платформой, демонстраций, проверки идей. Не подходит для: постоянного сайта с реальным контентом.

### Нужно полноценное облако?

Если спрос будет — сделаем полноценный управляемый хостинг. Напишите, что вам нужно: [trip2g.software@gmail.com](mailto:trip2g.software@gmail.com). Мы честно собираем обратную связь, прежде чем строить.
