Файлы Obsidian `.canvas`, `.base` и `.excalidraw` синхронизируются на сайт без ошибок. Но на вебе пока не рендерится ни один из них — вместо доски страница показывает короткую заглушку «пока не поддерживается». Полный рендеринг на вебе запланирован.

## Что работает сейчас

- **Синхронизация не ломается.** Положите `.canvas`, `.base` или `.excalidraw` в хранилище и синхронизируйте — файлы загрузятся и останутся доступными. Никаких сломанных страниц и ошибок.
- **Canvas управляет навигацией в Telegram.** Файл `.canvas` может работать как навигационный бот в Telegram: читатель ходит по вашим заметкам, следуя узлам и связям канваса, прямо внутри Telegram. См. [[telegram|Публикация в Telegram]].

## На вебе — пока заглушка

Откройте страницу `.canvas`, `.base` или `.excalidraw` на сайте — вместо доски будет строка вроде «Canvas files are not supported yet». Файл опубликован, на него можно ссылаться, просто он ещё не отрисовывается.

Так что если в хранилище есть такие файлы, публикация не сломается — читатель увидит понятное сообщение, а не пустую ошибку.
