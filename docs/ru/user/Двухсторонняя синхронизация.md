По умолчанию плагин работает в одну сторону: вы пишете в Obsidian, изменения уходят на сервер. Сервер ничего не меняет у вас.

Двухсторонняя синхронизация работает иначе: изменения идут в обе стороны. Если кто-то изменил файл на сервере — плагин скачает изменения к вам.

### Когда это нужно

**Работа в команде:**
Несколько человек редактируют одну базу знаний. Каждый видит изменения коллег.

**Автоматизация на сервере:**
Импорт постов из Telegram канала, генерация контента, обработка данных. Результаты появляются в вашем хранилище.

### Что важно знать

Двухсторонняя синхронизация может изменять ваши файлы. Плагин отслеживает изменения и разрешает простые конфликты автоматически.

Если вы и коллега изменили один файл одновременно — плагин покажет окно выбора:
- Оставить вашу версию
- Принять версию с сервера
- Сохранить обе версии

Сложные конфликты могут быть неочевидны. Обязательно настройте [[Бекапы|бекапы хранилища]] перед включением.

### Как включить

1. Откройте настройки плагина trip2g sync
2. Включите опцию «Two-way sync»
3. Нажмите синхронизацию — плагин проверит состояние сервера

При первой синхронизации плагин спросит, какую версию считать основной: локальную или серверную.

### Индикатор на иконке

Цветная точка на иконке синхронизации показывает состояние:

| Цвет | Значение |
|------|----------|
| 🔵 Синий | Есть изменения на сервере |
| 🟢 Зелёный | Есть локальные изменения |
| 🟠 Оранжевый | Изменения и там, и там |
| 🔴 Красный | Есть конфликты |
