Каждое утро агент читает, что делали участники команды вчера, и пишет дневную заметку. По понедельникам — недельную. Никто ничего не вводит вручную: данные берутся из trip2g-инстансов участников через MCP.

## Зачем это нужно

Когда несколько человек работают с агентами параллельно, возникает слепое пятно: каждый видит свою работу, но не видит соседнюю. Чтобы скоординироваться, нужно либо спросить — и прервать — либо копаться в чужих коммитах.

Дайджест-агент убирает оба варианта. Он сам читает чужие снапшоты и собирает картину.

## Дневная заметка

Каждое утро агент обходит участников из `team_activity/_projects.md`, делает MCP-запрос к их trip2g-инстансу, читает вчерашние снапшоты и пишет общую заметку:

```markdown
## 2026-05-23

**Алексей** — [[trip2g/projects/trip2g-infra]]
- Добавил job для steel-browser в Nomad
- Тесты: `nomad job validate steel-browser.nomad.hcl`

**Николай** — [[nicksenin/projects/knowlu]]
- Рефакторинг парсера транскриптов
- Обновил промпты для case-extraction
```

Файл уходит в `team_activity/digests/YYYY-MM-DD.md`.

## Недельная заметка

В понедельник агент агрегирует семь дневных заметок и сопоставляет с целями прошлой недели:

```markdown
## Неделя 21

**Алексей**
- Сделано: инфраструктура steel-browser, backup cross-node
- Переходит: MCP-эндпоинт для grafana

**Николай**
- Сделано: knowlu парсер v2, 14 новых кейсов
- Переходит: интеграция с Hermes

**Паттерны:** оба работали с MCP — хорошее место для синхронизации
```

## Страница команды

Дайджесты — для внутреннего использования. Но тот же агент может раз в сутки читать `whoami.md` каждого участника и обновлять публичную страницу команды на сайте. Каждый правит только свой файл у себя — агент собирает актуальный агрегат ночью.

## Координация без встреч

Дневная заметка — это ещё и сигнал. Перед тем как взять задачу, агент Николая читает вчерашний дайджест: если Алексей уже работает с этим модулем — задача переходит в очередь. Агент-to-агент координация через опубликованные данные, без общего планировщика и без Jira.

## Запуск

Дайджест-агент работает по крону через `CronCreate` в Claude Code:

```
ежедневно в 07:00 → читает MCP участников → пишет дайджест
еженедельно в пн 08:00 → агрегирует дневные → пишет недельную
```

Участники обнаруживаются через федеративный поиск по протоколу `agent-team` — подробнее в [[ru/thoughts/agent-team-reporting|Агент докладывает команде сам]].
