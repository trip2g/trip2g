Спустя чуть больше месяца после первого коммита про федерацию наш публичный
trip2g-хаб запущен: **один MCP-эндпоинт ищет сразу по нескольким независимым базам
знаний.** Демо — меньшая часть. Ставка — сеть: базы принадлежат разным людям,
доступны по одному адресу, и любой агент может по ним искать без центрального
реестра.

## Какую задачу он закрывает

Job-to-be-done: *когда агенту нужно обосновать ответ, я хочу, чтобы он искал по всем
базам, которым я доверяю — своим, партнёрским, нескольким курируемым публичным — через
один эндпоинт и получал лучшие источники, а я не возился с проводкой соединений.*

Никому не нужна «фича федерации». Нужно, чтобы агент стал умнее, потому что
дотягивается до большего числа хороших источников без единой строчки настройки.

## Какую проблему решает федерация

У каждого, кто держит trip2g, есть своя база, и агент, нацеленный на одну из них,
не видит остальные. Прописывать N эндпоинтов в конфиг каждого агента — трение,
которое растёт вместе с сетью. Мы хотели обратного: добавить базу одной заметкой —
и любой агент, нацеленный на хаб, до неё дотягивается.

Именно это делает MCP-федерация. **KB-заметка** — заметка с
`mcp_federation_kb_url` во frontmatter — регистрирует другую MCP-совместимую базу.
`federated_search` веером обходит их все и сливает результаты. Без центрального
реестра: заметки в вашем vault *и есть* топология.

## Что внутри хаба

- **Журнал Ника Сенина** — отфильтрованные кейсы Code with Claude 2026, собранные на
  собственном trip2g-инстансе Николая. Наш проверенный первый пир: агент достал эти
  кейсы по MCP, чтобы укрепить скил, ни разу не открыв сами выступления.
- **Марк Аврелий — Размышления** — наша база: все 12 книг на русском, английском и
  греческом, с комментарием, тематическими цепочками и извлечёнными принципами.
- **Telegram-каналы** — курируемый набор публичных каналов за trip2g-адаптером.

Каждая запись — двуязычная пара в [[ru/hub/_index|индексе хаба]]; добавить следующую —
одна заметка ([[ru/hub/_create|как]]).

## Публичная находимость, закрытый контент

Два слоя — намеренно. **Находимость публична** — любой видит, что база существует, и
адресует её по `kb_id`. **Контент можно закрыть** — Telegram-адаптер не отдаёт
анонимному вызову *ничего*: ни попаданий, ни текстов сообщений. Результат получает
только хаб с общим ключом. Так мы рекламируем базу в публичном хабе, не раскрывая её
содержимое; а открытым справочным базам ключ не нужен вовсе.

## Что дальше

Два хода, оба крупнее демо:

**Организовать работу команды поверх этой сети.** Агенты уже публикуют, что делают;
федерация даёт одному агенту видеть фокус и цели другого через тот же эндпоинт —
координация без созвонов, между организациями, без центрального сервера.

**Построить компанию поверх сети.** Хаб доверенных баз, агенты, координирующиеся
через него, контент и доступ как продукт — это не демо, это форма бизнеса. Публичный
хаб — первый кирпич.

Первый месяц: работает и запущено. Самое интересное начинается сейчас.
