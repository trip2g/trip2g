# Риски Telegram-аккаунта (авторизация через сторонние клиенты)

Касается случая, когда вы подключаете **личный Telegram-аккаунт** к trip2g по Telegram API (MTProto) — чтобы публиковать посты *от своего лица*, импортировать каналы или дать агенту действовать через ваш аккаунт. К ботам из [@BotFather](https://t.me/BotFather) это **не относится** — они безопаснее (см. в конце).

## Суть риска

Telegram жёстко контролирует аккаунты, используемые через **неофициальные** (сторонние / API) клиенты. Если за короткое время создать слишком много активности — **особенно повторно запрашивать код входа снова и снова** — Telegram временно помечает аккаунт. После этого **авторизация через сторонние клиенты перестаёт работать на какое-то время**: код входа тихо не приходит, либо вход не проходит. Официальные приложения при этом работают как обычно — блокируется только вход по API.

Мы поймали ровно это: повторные попытки входа → код перестал приходить, и **новый `app_id`/`api_hash` не помог**, потому что метка стоит на **номере / аккаунте**, а не на приложении.

## Что это вызывает

- **Многократный повторный запрос кода входа** за короткое окно (самая частая причина).
- Попытки войти **быстро с разных IP / дата-центров** (например, переключая серверы между попытками).
- **Массовые/всплесковые действия** через API — массовые отправки, быстрые циклы.
- Важно: **новый `app_id`/`api_hash` не чинит проблему**, если помечен сам номер.

## Симптомы

- Код входа **не приходит** (ни SMS, ни в служебном чате «Telegram») — молча.
- Вход не проходит или возвращает `FLOOD_WAIT` с временем ожидания.
- Действия отклоняются. Длительность обычно **от часов до нескольких дней**, иногда дольше.

## Как избежать

- **Запросите код один раз и ждите.** Не запрашивайте повторно — каждая повторная попытка может продлить блок.
- **Используйте номер, где уже есть активная официальная сессия** (телефон/десктоп). При входе по API Telegram присылает код **внутрь приложения** (служебный чат «Telegram»), а не по SMS — поэтому аккаунт с живой сессией получает код надёжно.
- **Не переключайте серверы/IP** между попытками входа. Выберите одно место и оставайтесь.
- Используйте **отдельный, «прогретый» номер**; избегайте всплесковых массовых действий; **уважайте `FLOOD_WAIT`** — если Telegram просит подождать N секунд, подождите.
- При публикации от лица аккаунта держите объёмы адекватными (trip2g ставит отправку в очередь; не лейте сотни разом).

## Если уже во флуд-бане

**Перестаньте дёргать** — новые попытки могут удлинить блок. Подождите (часы → дни), затем сделайте **одну** попытку и проверьте код в приложении Telegram. Снять флуд-лимит Telegram принудительно нельзя — помогает только время.

## Безопасный фолбэк (без авторизации по API)

Чтобы читать или анализировать свои чаты, не трогая авторизацию по API, используйте **экспорт Telegram Desktop** (Settings → Advanced → Export Telegram data, либо по чату Export chat history; формат JSON, без медиа). Это режим только-чтение и **никакого риска** для аккаунта.

## Бот против юзербота

Публикация через **бота** (токен BotFather) куда безопаснее и не подвержена этому риску входа. **Юзербот** (личный аккаунт через MTProto) оставляйте для того, что действительно нужно от лица человека — постинг как реальный пользователь, премиум кастом-эмодзи, импорт приватной истории. Если задачу может сделать бот — используйте бота.
