Ваши заметки и документация отвечают агентам по MCP: поиск возвращает нужный раздел с его местом в оглавлении, и агент читает только его. Инструкции, написанные обычной заметкой, агент получает при подключении, а именованные точки входа дают одной базе несколько ролей. Открыть можно всю базу или один подграф — и действуют её собственные правила доступа.
