Каждый человек, команда или агент пишет только в свою базу. Пространство компании собирается из этих баз федерацией: один MCP-эндпоинт, хаб рассылает вопрос по всем базам, и каждый ответ остаётся привязан к базе, из которой пришёл. Матрицы прав над одной общей вики нет — каждый владелец сам решает, что открывает его база. Это data mesh, только для знаний, а круг друзей — тот же случай, просто поменьше.
