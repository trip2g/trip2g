[03] company internal

Звезда: компания + сотрудники

Роль
Организация с общими документами и личными рабочими заметками сотрудников. Роли, области доступа, хранение.
Настройка
Один центральный hub хранит канонические данные. Каждый сотрудник запускает (или арендует) личный hub, связанный с центром.

Онбординг, история проектов, неформальные знания — всё доступно для запросов, но доступ к каждому vault остаётся гранулярным.

Данные хранятся там,
где вы решите.

trip2g — это протокол, а не вендор. Нет центрального сервера, от которого вы зависите, нет пикселя аналитики, нет теневой копии ваших заметок на чужом сервере.

Каждый хаб владеет своими данными и сам решает — по каждому подключению и каждой базе — что доступно для запросов, а что нет.

  • хранениеваш диск · ваш S3 · или наш sandbox 100MB
  • доступпереключатель на уровне базы · пауза в любой момент
  • peer'ытолько по согласию · доверие отзывается
  • сетьпрямое hub ⇄ hub · без relay
  • кодMIT · аудит, форк, запуск

Пропусти лендинг.
Спроси агента.

Не читай эту страницу. Вставь адрес MCP в Claude Code, Codex, Cursor или любой MCP-клиент — он подключится к живой демо-сети знаний и ответит на любой вопрос о trip2g. Быстрее чем читать.

// agent prompt · paste as-is 
# Подключи эту сеть знаний:
mcp:add https://trip2g.com/_system/mcp

# Теперь спроси что угодно, например:
- что такое trip2g и как работает сеть знаний?
- как подключить свой Obsidian vault?
- какая модель приватности? где хранятся данные?
- покажи минимальный конфиг чтобы поделиться базами с другом
- сравни trip2g с централизованным RAG сервисом

# Когда будешь готов:
mcp:add https://mcp.trip2g.com/me  # свой хаб, 100MB бесплатно
  1. step 01

    Возьмите MCP-агента

    Если ещё нет — Claude Code, Codex, Cursor или любой MCP-клиент. Пять минут на установку.

    claude code ↗ codex ↗ другие клиенты
  2. step 02

    Вставьте адрес → спросите что угодно

    Агент подключается к нашей публичной демо-сети по MCP и отвечает из реальных баз знаний. Без регистрации, без API-ключа.

  3. step 03

    Запустите свой хаб

    Убедились? Получите бесплатный sandbox на 100MB в нашем облаке — без docker, без терминала — и начните добавлять базы (Obsidian, Drive, TG). Перейдите на self-host, когда вырастете.

    simplecloud.2pub.me → руководство по self-host
  4. step 04

    Нужно больше? Напишите нам

    Федерация команды или двух компаний, кастомные адаптеры, on-prem? Вступайте в сообщество или запишитесь на 30-минутную консультацию — разберём вашу топологию.

    сообщество ↗ записаться ↗ github ↗
